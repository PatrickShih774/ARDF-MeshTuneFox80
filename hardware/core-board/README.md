# core-board 核心底板

## 1. 模块定位

整机的母板/背板。承载全部可插拔射频模块的排针排母插座、电源分配网络与 SMA 互联网络，是「核心底板 + 可插拔射频模块」架构的物理基础。

## 2. 关键指标

| 项目 | 指标 |
|------|------|
| 板卡尺寸 | 130×95mm |
| 层数 | 四层板 |
| 射频链路 | Si5351 → PA → LPF → ATU → ANT（50Ω，SMA 互联） |
| 电源分配 | 12V 功放轨 / 5V 主轨 / 3.3V 射频轨 / 3.3V 数字轨 |
| SMA 座数量 | 底板 3 个（模块侧共 6 个） |
| 时钟扩展 | 保留 32.768kHz 晶振 DNP 焊盘 |

## 3. 核心器件

- 模块排针座 ×6 组（2.54mm 排母）
- SMA 母座 ×3（底板侧射频互联）
- 电源分配网络：12V / 5V / 3.3V 射频 / 3.3V 数字 分离走线
- 天线座、电池座、接插件
- 32.768kHz 晶振 DNP 焊盘（Mesh 时钟可选升级）
- 高频去耦电容组（每个模块插座旁就近布置）

## 4. 接口

- 对 `pa-module`：射频输入、12V 轨、栅极偏置供电、键控 GPIO、PWM 调压
- 对 `lpf-module`：射频输入/输出 SMA
- 对 `atu-module`：射频输入/输出 SMA、12V 继电器轨、6 路继电器驱动 GPIO、SWR 前向/反射检波 ADC 通道
- 对 `mcu-ui-module`：I²C（Si5351）、SPI（LCD）、GPIO（编码器/按键/蜂鸣器）、3.3V 数字轨
- 对 `power-module`：电池输入、4 路电压轨输出
- 引脚分配以 `docs/05-hw-sw-interface-contract.md` 为唯一权威来源

## 5. 目录内容

| 子目录 | 内容 |
|--------|------|
| `schematic/` | 底板原理图源文件 |
| `pcb/` | 底板 PCB 源文件（四层堆叠定义） |
| `gerber/` | 制板 Gerber 包 |
| `bom/` | 底板物料清单 |
| `mechanical/` | 安装孔位、板框、模块间距、结构尺寸图 |

## 6. 验证要点

- 四层板电源平面完整性：各电压轨压降与噪声实测。
- 模块插拔：排针排母插拔寿命、接触可靠性。
- SMA 互联：力矩拧紧后 50Ω 阻抗连续性与插损。
- 模块间距与外壳装配干涉检查（与 `enclosure/` 联合验证）。
- 地平面分割检查：数字地与射频地单点汇接，避免数字噪声串入射频链路。
