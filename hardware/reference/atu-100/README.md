ATU-100（N7DDC 开源 100W 自动天调）的**参考摘录目录**，仅存放本地比对用的原理图/源码摘录。本工程从 ATU-100 借鉴的是 **调谐算法思想** 与 **继电器驱动方案**，不直接复制其代码。

## 4. 本工程借鉴范围

**软件层面（仅借鉴算法思想）**

ATU-100 调谐算法可概括为三阶段：

1. **粗调（Grundmatch）**：快速扫描预定义搜索表，找到 SWR 相对较低的起点。
2. **细调（Feinabstimmung）**：从起点开始采用坐标下降法（爬山搜索），每次只改变一个继电器状态并测量 SWR，保留改善方向，直到单参数改变无法获得更好 SWR。
3. **全遍历兜底**：若细调后 SWR 仍 >2.0，则全遍历 64 组取全局最优。

本工程将该思想 **移植到 ESP-IDF / ESP32-C3**，对应**私有固件仓**的 `components/atu_tuner/`。配套设计取舍：

- NVS 存储最佳组合，下次开机直接加载，微调 <0.5 秒。
- 低功率探测扫点：E 类功放 + ATU 搜索采用低功率扫点，避免满功率遍历导致 BS170 击穿。
- 调谐时间：粗调+细调约 2–4 秒，全遍历约 5 秒。

**硬件层面（借鉴继电器 + 驱动拓扑）**

- 继电器：HK4100F-DC-12V（SPDT，线圈 12V/720Ω，16.7mA，动作 6ms/释放 4ms）。
- 驱动：2N7002 低边驱动 + 100Ω 栅极电阻抑制振铃 + 10kΩ 下拉确保关断 + 1µF 陶瓷电容跨接线圈限制反峰（可并联 1N4148 冗余）。
- 匹配网络：3 电感 + 3 电容共 6 只继电器，64 种组合。

## 5. 使用限制

1. **禁止直接复制未经许可核对的代码**。本工程仅借鉴算法思想与电路拓扑；如需复制任何片段，必须先逐项核对 ATU-100 的原始许可证与署名/同许可分发要求。
2. 本目录 **不纳入本仓库版本管理与许可证范围**，第三方内容按其原始许可执行。
3. 摘录文件必须标注来源项目、原始版本/commit 与许可。
4. 硬件参数不得照搬：ATU-100 面向 100W 设计，本工程功率等级为 0.02–2.5W，元件耐压、磁环选型与线径均按本工程实测数据重新确定。
