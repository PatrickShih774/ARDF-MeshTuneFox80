# lpf-module 低通滤波模块

## 1. 模块定位

射频输出低通滤波器模块，位于功放与 ATU 之间，用于抑制 E 类功放开关工作产生的谐波，使整机满足 ARDF 竞赛对杂散辐射的要求。

## 2. 关键指标

| 项目 | 指标 |
|------|------|
| 滤波器类型 | 三阶椭圆低通 |
| 中心频率 | 3.55MHz |
| 通带 | 3.5–3.6MHz（80 米波段） |
| 2f₀ 衰减 | 7.1MHz 处 ≥55dB |
| 带内插损 | 越低越好（实测登记） |
| 阻抗 | 50Ω |

## 3. 核心器件

- 滤波电感：磁环绕制电感（具体磁环型号与圈数见 `schematic/` 与 `bom/`）
- 滤波电容：NP0 陶瓷电容（耐压按谐振点高压留足裕量）
- 屏蔽：模块金属屏蔽罩（可选，抑制辐射耦合）

## 4. 接口

- 射频输入：来自 `pa-module` 输出（SMA）
- 射频输出：至 `atu-module` 输入（SMA）
- 无源模块，不需要供电与控制信号

## 5. 目录内容

| 子目录 | 内容 |
|--------|------|
| `schematic/` | 滤波器原理图源文件（含元件值） |
| `pcb/` | 滤波器 PCB 源文件 |
| `gerber/` | 制板 Gerber 包 |
| `bom/` | 物料清单（磁环、漆包线、NP0 电容） |
| `test/` | 插损与谐波衰减实测报告（含 SDR 频谱截图） |

## 6. 验证要点

- **2 次谐波 7.1MHz 衰减 ≥55dB**（SDR 接收机实测）。
- **带内插损**：3.5/3.55/3.6MHz 三点插损实测并登记。
- 带内平坦度：3.5–3.6MHz 内起伏实测。
- 三次谐波 10.65MHz 衰减实测（作为余量参考）。
- 与功放联调：2.5W 输出下滤波器温升与元件耐压检查。
