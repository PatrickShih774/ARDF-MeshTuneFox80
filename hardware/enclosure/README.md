# enclosure 外壳与结构

## 1. 模块定位

整机外壳与结构件设计区，提供两种可选路径：**3D 打印件** 或 **通用塑料盒** 改制。负责模块固定、面板开孔、散热风道与现场部署的机械可靠性。

## 2. 关键指标

| 项目 | 要求 |
|------|------|
| 方案 | 3D 打印 或 通用塑料盒（可选） |
| 内部容纳 | 核心底板 130×95mm + ATU 模块 55×65mm + 电池 2S 500mAh |
| 面板开孔 | LCD 12864 视窗、EC11 旋钮孔、按键孔、SMA 座孔、天线座孔 |
| 散热 | BS170 区域通风；功放 2.5W 连续 30 分钟不超温 |
| 成本目标 | 约 5 元/套（3D 打印或通用盒） |

## 3. 核心器件

- 3D 打印件：上下壳、模块支架、LCD 压框、电池仓
- 通用塑料盒：按底板尺寸选型并手工开孔
- 紧固件：M3 铜柱与螺钉、自攻螺钉
- 面板件：亚克力或 PCB 材质面板
- 可选：散热片/通风栅格、SMA 与天线座安装法兰

## 4. 接口

- 与 `core-board`：安装孔位对齐（130×95mm 板框与固定柱）
- 与 `atu-module`：55×65mm 模块的独立固定位与 SMA 出线空间
- 与 `antenna`：天线座引出位置与馈线弯曲半径
- 与 `mcu-ui-module`：LCD 视窗、EC11 旋钮、双按键、蜂鸣器出声孔
- 无电气接口，仅机械接口

## 5. 目录内容

| 子目录 | 内容 |
|--------|------|
| `3d-print/` | 3D 打印模型与打印参数（STL/STEP/3MF） |
| `panel/` | 面板开孔图纸（DXF/PDF）与丝印内容 |

## 6. 验证要点

- **装配干涉检查**：底板、各模块、电池、线束在壳体内部无干涉；SMA 跳线弯曲半径满足要求。
- **散热风道检查**：BS170 与升压模块区域通风路径顺畅，2.5W 连续 30 分钟壳内温升可接受。
- 面板开孔位置公差核对（与 `interconnect/` 连接器定义联合验证）。
- 现场可靠性：悬挂/搬运状态下外壳无松脱，天线座受力不传递到 PCB。
- 3D 打印件层间强度与螺钉柱强度检查。
