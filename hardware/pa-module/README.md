# pa-module 功放模块

## 1. 模块定位

射频功率放大模块，将 Si5351 本振的毫瓦级信号放大到 ARDF 竞赛所需的 0.02–2.5W 可调输出。采用 **3× BS170 并联 E 类（开关模式）** 方案，兼顾成本、效率与微功率档能力。

## 2. 关键指标

| 项目 | 指标 |
|------|------|
| 拓扑 | 3× BS170 并联，E 类开关功放 |
| 额定输出功率 | 1–2.5W（长期安全运行） |
| 峰值短时功率 | 3.5W（限时 ≤30 秒，需散热片） |
| 低功率档 | 0.02–0.5W（PWM 调升压模块输出电压实现） |
| 漏极电压 | 12–13.8V |
| 栅极偏置 | 约 2.1V 直流（使管子工作于开关状态） |
| 效率 | 60%–73% |
| 功率调节 | 输出功率近似正比于 V_dd²，PWM 调节升压反馈网络 |

## 3. 核心器件

- 功放管：3× BS170（TO-92），总耗散能力约 1.05–2.5W
- 栅极偏置：10kΩ + 2.2kΩ 分压（自 5V LDO 取得约 2.1V）——**纯固定偏置，无温度补偿**
- ~~温度补偿：分压电阻下端串联 NTC 热敏电阻（10kΩ B=3950）~~ → 🔴 **已于 2026-09-26 从 BOM 取消**，理由见 §8.1
- 旁路电容：100nF 陶瓷电容
- 栅极保护：BZX84-C10（10V 双向稳压二极管）
- 备选方案：需 5W 输出时换用 IRF510（TO-220，Pd=20W），预留兼容焊盘
- 散热：TO-92 散热片 / 底板铺铜散热

## 4. 接口

- 射频输入：来自 Si5351 本振（50Ω）
- 射频输出：至 `lpf-module`（SMA）
- 12–13.8V 漏极供电：来自 `power-module` 升压模块
- 栅极偏置供电：5V 主轨
- 键控输入：ESP32-C3 GPIO 键控方波（A1A 调制，软起软降 2–5ms）
- 功率控制：ESP32-C3 PWM → 升压模块反馈网络

## 6. 验证要点

- **BS170 壳温 <85°C**（2.5W 连续发射 30 分钟，热电偶实测 TO-92 壳温）。
- **PWM 调压 0.02–0.1W 档位可用**（微功率档实际输出功率实测）。
- **栅极方波边沿无显著劣化**（方波边沿未因稳压管寄生电容显著劣化）。
- 超限处置：若壳温实测超限，将额定功率下调至 2W，或启用 IRF510 兼容焊盘。
- 输出功率与效率实测：对照 V_dd 与输出功率表（12V→2.5W、5V→0.43W、3V→0.15W、2V→0.07W、1.5V→0.04W）。

## 8. 决策记录

### 8.1 取消 NTC 温度补偿并删除 NTC（2026-09-26，用户决策）

| 项 | 内容 |
|---|---|
| **决策日期** | 2026-09-26 |
| **决策人** | 项目所有者（用户拍板） |
| **选定** | **本模块 BOM 删除 NTC 10kΩ B=3950 热敏电阻**；栅极偏置改为**纯固定偏置** |
| **同步** | 固件取消 NTC 测温与过温联锁，遥测帧删除温度字段（**18 → 16 字节**） |
| **完整记录** | [docs/17 §12.5](../../docs/17-gpio-allocation-audit.md) |

**为什么取消**

- 🔴 **没有 ADC 通道可分配给 NTC**。MCU 侧 `drv_analog` 的 **12 个可用 GPIO（GPIO0–8、10、12、13）
  已全部用满**，其中 ADC1 的 5 个通道（CH0–CH4）**无一空闲**：

  | ADC1 通道 | 引脚 | 已被谁占用 |
  |---|---|---|
  | CH0 | GPIO0 | `ADC_FWD` SWR 前向检波 |
  | CH1 | GPIO1 | `ADC_REV` SWR 反射检波 |
  | CH2 | GPIO2 | `EC11_A` 编码器 A 相（且是 strapping 脚） |
  | CH3 | GPIO3 | `ADC_VBAT` 电池电压 |
  | CH4 | GPIO4 | `I2C_SDA` I²C 数据线 |

  即**"用 MCU 读 NTC"这条路径在本板上物理不可实现**；要腾通道就得牺牲 SWR 检波、
  电池监测、编码器或 I²C 之一，代价远高于收益。
- 既然**固件根本读不到这个 NTC**，保留它就只剩 **BOM 成本、装配工序与一个可能虚焊的模拟节点**，
  于是**整体取消**（而不是"先装上、以后再说"）。

**连带变更**

| 位置 | 变化 |
|---|---|
| 本模块 BOM / §3 核心器件 | 删除 NTC 10kΩ B=3950 |
| 本模块栅极偏置 | 由"分压 + NTC 温度补偿"改为**纯固定偏置**（分压电阻下端直接接地） |
| `hardware/README.md`、`docs/04` §3.2 | 器件行与偏置描述同步删除 NTC |
| 固件 `drv_analog` | 删除 `drv_analog_ntc_millicelsius()` 及其全部单测断言 |
| 固件 `app_core` / `ui_menu` / `rf_power` / `comm_console` | 删除温度字段、温度显示、过温联锁原因位；遥测帧 18 → 16 字节 |

**⚠️ 取消的代价（必须知情）**

- 🔴 **失去功放温度保护**：本模块**不再有任何温度传感**，长时间满功率（1–2.5W）发射时，
  BS170 壳温**只能靠 §3 的散热设计与发射占空比保证**，固件不会因过热而降功率或断功放。
- **兜底手段**：固件 `pa_scan()` 的 **3.5 W 峰值 ≤30 s 超时**（`RF_POWER_REASON_PEAK_TIMEOUT`）
  只覆盖**峰值档**；**额定档 2.5 W 连续发射没有任何时间限制**——这是明确的功能缺口。
- **减损措施**：§6 的壳温实测判据（**2.5 W 连续 30 分钟 TO-92 壳温 <85°C**）成为
  负载能力的**唯一依据**，必须按实际散热条件重新验证。若实测超限，按 §6 处置：
  额定功率下调至 2W，或启用 IRF510（TO-220，Pd=20W）兼容焊盘。
- **恢复路径**：若日后重新需要热保护，建议走 **I²C 数字温度传感器**（不占 ADC 通道），
  但需新增器件并在已挂 TCA9535 与 LCD 的 I²C 总线上规划地址。
