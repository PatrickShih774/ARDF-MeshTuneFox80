# pa-module 功放模块

## 1. 模块定位

射频功率放大模块，将 Si5351 本振的毫瓦级信号放大到 ARDF 竞赛所需的 0.02–2.5W 可调输出。采用 **3× BS170 并联 E 类（开关模式）** 方案，兼顾成本、效率与微功率档能力。

## 2. 关键指标

| 项目 | 指标 |
|------|------|
| 拓扑 | 3× BS170 并联，E 类开关功放 |
| 额定输出功率 | 1–2.5W（长期安全运行） |
| 峰值短时功率 | 3.5W（限时 ≤30 秒，需散热片） |
| 低功率档 | 0.02–0.5W（PWM 调升压模块输出电压实现） |
| 漏极电压 | 12–13.8V |
| 栅极偏置 | 约 2.1V 直流（使管子工作于开关状态） |
| 效率 | 60%–73% |
| 功率调节 | 输出功率近似正比于 V_dd²，PWM 调节升压反馈网络 |

## 3. 核心器件

- 功放管：3× BS170（TO-92），总耗散能力约 1.05–2.5W
- 栅极偏置：10kΩ + 2.2kΩ 分压（自 5V LDO 取得约 2.1V）
- 温度补偿：分压电阻下端串联 NTC 热敏电阻（10kΩ B=3950）
- 旁路电容：100nF 陶瓷电容
- 栅极保护：BZX84-C10（10V 双向稳压二极管）
- 备选方案：需 5W 输出时换用 IRF510（TO-220，Pd=20W），预留兼容焊盘
- 散热：TO-92 散热片 / 底板铺铜散热

## 4. 接口

- 射频输入：来自 Si5351 本振（50Ω）
- 射频输出：至 `lpf-module`（SMA）
- 12–13.8V 漏极供电：来自 `power-module` 升压模块
- 栅极偏置供电：5V 主轨
- 键控输入：ESP32-C3 GPIO 键控方波（A1A 调制，软起软降 2–5ms）
- 功率控制：ESP32-C3 PWM → 升压模块反馈网络

| 子目录 | 内容 |

## 6. 验证要点

- **BS170 壳温 <85°C**（2.5W 连续发射 30 分钟，热电偶实测 TO-92 壳温）。
- **PWM 调压 0.02–0.1W 档位可用**（微功率档实际输出功率实测）。
- **栅极方波边沿无显著劣化**（方波边沿未因稳压管寄生电容显著劣化）。
- 超限处置：若壳温实测超限，将额定功率下调至 2W，或启用 IRF510 兼容焊盘。
- 输出功率与效率实测：对照 V_dd 与输出功率表（12V→2.5W、5V→0.43W、3V→0.15W、2V→0.07W、1.5V→0.04W）。
