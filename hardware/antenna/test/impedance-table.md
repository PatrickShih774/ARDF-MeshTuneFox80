## 2. 未匹配时的严重程度（由记录值推算）

`z = Z/50 = 2.4 − j21` ⇒ Smith 图上落在**底部（强容性）边缘**，`|Γ| ≈ 0.95` ⇒ **SWR ≈ 47:1** ✗
⇒ 这就是"无匹配网络时发射效率极低"的量化依据 ✓
**匹配轨迹**：串联 L 沿**等电阻圆顺时针**上行（补 −jX）→ 并联 C 再**旋到圆心（50 Ω）** ✓
