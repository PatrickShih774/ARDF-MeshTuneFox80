# antenna 天线与地线系统

## 1. 模块定位

天线与地线系统，是整机辐射效率的决定性环节。80 米波段短导线天线的输入阻抗呈 **高电抗、低辐射电阻** 特性，必须配合 `atu-module` 匹配网络使用；无匹配网络时发射效率极低。本目录存放天线形态设计资料与 NanoVNA 实测记录。

## 2. 关键指标

| 项目 | 要求 |
|------|------|
| 天线长度 | **5 米**（推荐），最小 4 米，最大 8 米 |
| 地线 | **至少 5 米**，推荐 3 段×2 米辐射状铺设 |
| 极化 | 垂直 |
| 架设方式 | 垂直悬挂，远离树干和金属物体 |
| 工作频率 | 3.5–3.6MHz |
| 部署后操作 | **必须重新调谐**，NVS 记忆仅作起点 |

**实测典型阻抗（3.5MHz）**

| 场景 | 实部 R | 虚部 X | 所需串联电感 | 所需并联电容 |
|------|--------|--------|-------------|-------------|
| 挂树状态 | ≈120Ω | ≈-1050Ω | 约 30–34 µH | 约 25 pF |
| 实验室状态 | 50–88Ω | ≈-1100Ω | 约 35–50 µH | 0–450 pF |

## 3. 核心器件

- 5 米垂直导线（多股软铜线或镀锡铜线，便于悬挂与收放）
- 地线：3 段×2 米辐射状导线 + 地钉
- 天线座 / 馈线：SMA 座与同轴馈线（对接 `atu-module` 输出）
- 悬挂件：绝缘绳、抛绳器/弹弓、绝缘支撑杆
- 测量仪器：NanoVNA-F（或同类手持矢量网络分析仪）

## 4. 接口

- 射频接口：SMA 母座，接 `atu-module` 天线输出端
- 无供电与控制信号
- 匹配关系：串联电感约 29.8–34µH（挂树）/ 35–50µH（实验室），并联电容 0–472pF 由 ATU 64 组合覆盖

## 5. 目录内容

| 子目录 | 内容 |
|--------|------|
| `design/` | 天线形态设计资料（长度选择、地线布局、悬挂方案、匹配换算表） |

## 6. 验证要点

- **NanoVNA 实测 3.5MHz 阻抗**：每个测点记录 R、X 与匹配轨迹，整理成对照表。
- **挂树状态**：实测 R≈120Ω / X≈-1050Ω，需串联电感约 **30–34µH**、并联电容约 **25pF**。
- **实验室状态**：实测 R≈50–88Ω / X≈-1100Ω，需串联电感约 **35–50µH**、并联电容 **0–450pF**。
- 判定准则：实测所需串联电感落在 **0–92µH** 内、所需并联电容落在 **0–472pF** 内（即 ATU 可覆盖范围）。
- 43 材质磁环在 3.5MHz 的 µ'' 值测量（耦合器设计输入）。
- 现场验证：架设 5m 导线 + 5m 地线，2W 下调谐后 SWR<2.0。
- 部署复现性：改变悬挂高度/周边环境后必须重新调谐，验证 NVS 记忆仅作起点。
