# atu-module 自动天调模块

## 1. 模块定位

自动天线调谐（ATU）模块，把 5 米短垂直导线天线的高电抗、低辐射电阻负载匹配到 50Ω。采用 **6 只继电器构成的 L 型匹配网络**（3 电感 + 3 电容），共 **64 种组合**，覆盖挂树与实验室两类实测天线状态。继电器与驱动方案借鉴 ATU-100。

## 2. 关键指标

| 项目 | 指标 |
|------|------|
| 板卡尺寸 | 55×65mm（因 HK4100F 封装较大） |
| 匹配拓扑 | L 型；3 电感 + 3 电容 |
| 组合数 | 64 种（8 电感组合 × 8 电容组合） |
| 电感组合 | 0/12/33/45/47/59/80/92 µH |
| 电容组合 | 0/22/120/142/330/352/450/472 pF |
| 覆盖能力 | 挂树 30–34µH（选 33µH，SWR<2.5）；实验室 35–50µH（选 45/47µH，SWR<1.8–2.0） |
| 无功电流 | 调谐后回路约 0.408A rms |
| 调谐时间 | 粗调+细调 2–4 秒，全遍历约 5 秒 |

## 3. 核心器件

**继电器：6× HK4100F-DC-12V**（K1–K3 电感，K4–K6 电容）

| 参数 | 数值 |
|------|------|
| 触点形式 | SPDT（1C） |
| 触点容量 | 3A @ 250VAC / 30VDC |
| 线圈电压 / 电阻 | 12VDC / 720Ω |
| 线圈额定电流 | 16.7mA（6 只同时吸合约 100mA） |
| 动作 / 释放时间 | 6ms / 4ms |
| 接触电阻 | 100mΩ |
| 封装 | DIP，14.5×10.5mm |
| 寿命 | 电气 10 万次 / 机械 1000 万次 |

**电感阵列**

| 位 | 电感值 | 磁芯 | AL 值 | 绕制参数 |
|----|--------|------|-------|---------|
| L1 | 12 µH | T37-6 | 3.0 nH/N² | 约 63 圈 |
| L2 | 33 µH | T106-6 | 11.6 nH/N² | 约 53 圈 |
| L3 | 47 µH | T106-6 | 11.6 nH/N² | 约 64 圈 |

T106-6 SRF 约 6.0MHz；绕组推荐 0.5mm 漆包线（3.5MHz 趋肤深度约 35µm）。

**电容阵列**

| 位 | 电容值 | 继电器 | 接入条件 |
|----|--------|--------|---------|
| C3 | 22 pF | K4 | K4 吸合时接入 |
| C4 | 120 pF | K5 | K5 吸合时接入 |
| C5 | 330 pF | K6 | K6 吸合时接入 |

全部选用 **NP0 1206/1812，耐压 ≥630V**（谐振高压可达 816Vrms）。

**驱动电路：2N7002 + 100Ω 栅极电阻 + 10kΩ 下拉 + 1µF 陶瓷电容**

- 每路继电器由 2N7002 低边驱动，栅极串 **100Ω** 抑制振铃，**10kΩ** 下拉确保关断。
- 线圈两端跨接 **1µF 陶瓷电容** 限制反电动势（约 20V，2N7002 Vdss=60V）。
- 可**并联 1N4148 续流二极管** 作为冗余保护，两者不冲突。
- 2N7002 在 3.3V GPIO 下 Rds(on) 约 1.6–4.5Ω，16.7mA 线圈电流下压降仅 0.03–0.08V。

**其他**

- SWR 检测：Tandem Match 定向耦合器（T1/T2 为 FT37-43，初级 1 匝穿芯 + 次级 10 匝，耦合度 20dB，R_sense 初始 1kΩ），检波 1N5711 与 HSMS-2850 并行对照，可选 LM358 放大。
- 天线静电泄放：输入端 1kV 高压电阻 100kΩ 到地，或射频专用 GDT。

## 4. 接口

- 射频输入：来自 `lpf-module`（SMA）
- 射频输出：至天线座（SMA）
- 继电器电源：12V 功放轨
- 控制：6 路 GPIO（K1–K6），经 2N7002 驱动
- 反馈：SWR 前向/反射两路检波 → ADC；SWR>3.0 时固件禁止发射
- 引脚分配以 `docs/05-hw-sw-interface-contract.md` 为唯一权威来源

## 6. 验证要点

- **继电器插入损耗 <0.1dB @3.5–3.6MHz**。
- **隔离度 >40dB**。
- **100 次切换后接触电阻变化 <20mΩ**。
- **2.5W 连续 30 分钟后接触电阻漂移 <30mΩ**。
- **6 只继电器同时吸合电流 <110mA**。
- **1µF 电容反峰抑制实测反峰 <25V**（示波器）。
- **T106-6 磁环表面温度 <70°C**（模拟 15-j2000Ω 负载，2.5W 连续 30 分钟）。
- 静态遍历：50Ω 负载下 ≥8 种组合 SWR<1.2；100/150Ω 与 10/20Ω 负载下各 ≥3 种组合 SWR<2.0。
- 模拟天线：120-j1050Ω 验证 33µH 档 SWR<2.5；50-j1110Ω 验证 47µH 档 SWR<1.8；88-j1030Ω 验证 45µH 档 SWR<2.0。
- 耦合器：耦合度 20±3dB，方向性 >25dB，带内平坦度 <1.0dB。
