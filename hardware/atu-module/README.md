# atu-module 自动天调模块

## 1. 模块定位

自动天线调谐（ATU）模块，把 5 米短垂直导线天线的高电抗、低辐射电阻负载匹配到 50Ω。采用 **6 只继电器构成的 L 型匹配网络**（3 电感 + 3 电容），共 **64 种组合**，覆盖挂树与实验室两类实测天线状态。继电器与驱动方案借鉴 ATU-100。

## 2. 关键指标

| 项目 | 指标 |
|------|------|
| 板卡尺寸 | 55×65mm（因 HK4100F 封装较大） |
| 匹配拓扑 | L 型；3 电感 + 3 电容 |
| 组合数 | 64 种（8 电感组合 × 8 电容组合） |
| 电感组合 | 0/12/33/45/47/59/80/92 µH |
| 电容组合 | 0/22/120/142/330/352/450/472 pF |
| 覆盖能力 | 挂树 30–34µH（选 33µH，SWR<2.5）；实验室 35–50µH（选 45/47µH，SWR<1.8–2.0） |
| 无功电流 | 调谐后回路约 0.408A rms |
| 调谐时间 | 粗调+细调 2–4 秒，全遍历约 5 秒 |

## 3. 核心器件

**继电器：6× `HK4100F-DC5V-SHG`**（K1–K3 电感，K4–K6 电容；🔴 **2026-10-11 由 DC-12V 改为 5 V 线圈**）

| 参数 | 数值 |
|------|------|
| 触点形式 | SPDT（1C） |
| 触点容量 | 3A @ 250VAC / 30VDC |
| 线圈电压 / 电阻 | 🔴 **5 VDC / 125 Ω**（~~12 VDC / 720 Ω~~ 已废） |
| 线圈额定电流 | 🔴 **40 mA**（6 只同时吸合约 **240 mA**，走 `+5 V` 轨） |
| 动作 / 释放时间 | 6 ms / 4 ms（⚠️ 5 V 线圈型号的动作时间**未实测**，固件 Kconfig 仍按 5/8 ms） |
| 接触电阻 | 100mΩ |
| 封装 | DIP，14.5×10.5mm |
| 寿命 | 电气 10 万次 / 机械 1000 万次 |

**电感阵列**

| 位 | 电感值 | 磁芯 | AL 值 | 绕制参数 |
|----|--------|------|-------|---------|
| L1 | 12 µH | T37-6 | 3.0 nH/N² | 约 63 圈 |
| L2 | 33 µH | T106-6 | 11.6 nH/N² | 约 53 圈 |
| L3 | 47 µH | T106-6 | 11.6 nH/N² | 约 64 圈 |

T106-6 SRF 约 6.0MHz；绕组推荐 0.5mm 漆包线（3.5MHz 趋肤深度约 35µm）。

**电容阵列**

| 位 | 电容值 | 继电器 | 接入条件 |
|----|--------|--------|---------|
| C3 | 22 pF | K4 | K4 吸合时接入 |
| C4 | 120 pF | K5 | K5 吸合时接入 |
| C5 | 330 pF | K6 | K6 吸合时接入 |

全部选用 **NP0 1206/1812，耐压 ≥630V**（谐振高压可达 816Vrms）。

**驱动电路：单颗 CA-DV8008N（当前方案，2026-10-11 起）**

> 🔴 **现行方案 = 单颗 `CA-DV8008N`**（I²C 八通道低边驱动，**7 位地址 `0x28`**，立创 C54557228）：
> `COM → +5 V`（内部钳位共阴）；`OC1–OC6` 分别低边驱动 **K1–K6**（5 V / 125 Ω / 40 mA），
> **6 只同时 ≈240 mA**；`OC7/OC8` **保持空闲、不预接、固件点不到**；`A0/A1/A2 → GND`。
> 上电/复位时器件输出寄存器 = 0 ⇒ 8 路高阻 ⇒ **K1–K6 全释放 = 0 µH/0 pF 直通**（安全态由器件自身保证，
> **不再需要** ULN2003A 时代的 `R_RLY1–R_RLY6` 输入下拉，BOM 已删）。
> 12 位（3 电感 + 3 电容）组合与 `relay_mask` 位序契约不变（`bit i ⇔ K(i+1)`），见 [`relay-wiring.md`](relay-wiring.md)。
> 权威出处：[docs/05](../../docs/05-hw-sw-interface-contract.md) §2.3/§2.4 与 [relay-wiring.md 顶部 CHANGELOG](relay-wiring.md)。

```
ESP32 GPIO4/5 (I²C 3.3V)
      ↓
   CA-DV8008N（3.3 V 逻辑，I²C 0x28）   ← 单颗解决「引脚 + 驱动 + 续流」
      ↓ OC1–OC6（低边，开漏拉低）
   继电器 K1–K6 线圈（5 V，40 mA/只；另一端接 +5 V）
      ↓
   ✅ COM 引脚必须接 +5 V（内部续流钳位共阴）
```

- **元件数**：CA-DV8008N ×1 = **1 颗**，替代 `TCA9535 + ULN2003A`（2 颗）与更早的 2N7002 分立方案（约 24 个元件）。
- **校核**：CA-DV8008 每路 ≥100 mA（本项目 40 mA/只，余量充足）；低边饱和压降按器件手册 ⇒ 线圈实际电压需按 5 V 轨复核（**待实测**）。

**历史（已废）驱动电路 ①：TCA9535 → ULN2003A 达林顿链（2026-09-26 起，2026-10-11 被取代）**

- `TCA9535`（I²C 16 位扩展器，`0x20`）`P0.0–P0.5` → `ULN2003A`（7 路达林顿，用 6 路）→ 12 V 线圈；
  `ULN2003A` 的 **COM 必须接 +12 V**（内部续流二极管靠它生效）；需 6 只 10 kΩ 输入下拉。
- 元件数 2 颗；校核：ULN2003A 500 mA/路、16.7 mA/只。**⚠️ 此链与 12 V 线圈均已作废，勿据以下单。**

**历史（已废）驱动电路 ②：2N7002 + 100Ω 栅极电阻 + 10kΩ 下拉 + 1µF 陶瓷电容（2026-09-26 前）**

- 每路继电器由 2N7002 低边驱动，栅极串 **100Ω** 抑制振铃，**10kΩ** 下拉确保关断。
- 线圈两端跨接 **1µF 陶瓷电容** 限制反电动势（约 20V，2N7002 Vdss=60V）。
- 可**并联 1N4148 续流二极管** 作为冗余保护，两者不冲突。
- 2N7002 在 3.3V GPIO 下 Rds(on) 约 1.6–4.5Ω，16.7mA 线圈电流下压降仅 0.03–0.08V。

**其他**

- SWR 检测：Tandem Match 定向耦合器（T1/T2 为 FT37-43，初级 1 匝穿芯 + 次级 10 匝，耦合度 20dB，R_sense 初始 1kΩ），检波 1N5711 与 HSMS-2850 并行对照，可选 LM358 放大。
- 天线静电泄放：输入端 1kV 高压电阻 100kΩ 到地，或射频专用 GDT。

## 3.5 SWR 检测电路（Tandem Match）

**方案名称**：**Tandem Match（串联匹配式定向耦合器）**，亦称 **Stockton 桥** —— 与 **ATU-100（N7DDC）** 同款拓扑。

```
RF_IN ─┬─[T1 1:10]─┬─[T2 1:10]─┬─ 主线 → LC 匹配网络 → 天线
       │            │            │
   次级A端       串接点        次级B端
       │                          │
  R_term = 50 Ω / 1 W         R_term = 50 Ω / 1 W      ← 次级 AC 终端（= Z₀，桥的成立条件）
       │                          │
  D3(1N5711)+D4(HSMS-2850占位)  D1(1N5711)+D2(HSMS-2850占位)
       │                          │
  C(10nF) → R(68k) → C(10nF)    同左（两级 C-R-C）
       │                          │
   ADC_REV                     ADC_FWD      ← 🔴 极性必须实测（见下）
```

| 器件 | 作用 |
|---|---|
| **T1 / T2** | 两芯穿**同一根主线**（初级 1 匝），次级 **N=10 匝** ⇒ **耦合度 20·log₁₀10 = 20 dB**（与"20±3 dB"口径自洽）；T1 取电流、T2 取电压；**FWD/REV 是两端串接后的和/差**，不是单独从某一只出来 |
| **`R_term` = 50 Ω / 1 W（2512，配对 1%）** | 次级 **AC 终端负载**；🔴 **必须 = 50 Ω**（≠ 50 Ω 则方向性崩塌）；2.5 W 时 `V_det ≈ V_line/N ≈ 1.12 V` ✅ |
| **D1–D4** | **肖特基峰值检波**（`V_F` 0.15–0.3 V；硅管在 QRP 下检不出）；小信号为平方律 ⇒ 需多点软件标定 |
| **检波后 C-R-C** | **10 nF + 68 k + 10 nF（C0G）** ⇒ τ=0.68 ms、3.55 MHz 抑制 −83 dB、64 组合调谐 0.5–1 s ✅（选值依据见 `docs/05` §3.2.4） |
| **ADC 节点 100 kΩ 到地（建议）** | 给滤波电容定义放电通路（否则只靠 ADC 高阻输入） |

🔴 **投板前必做——FWD/REV 极性实测**：天线口接 **50 Ω 假负载**（≥5 W）⇒ 发 1–2 W 载波 ⇒ 量 `ADC_FWD`/`ADC_REV` 直流 ⇒ **读数大的一端 = FWD**，另一端应 ≤ −25 dB（方向性）；**若反了只需把两处标签对调**（无需重绕）。开路/短路时两端近似相等（全反射参考点）。

**方案对比与选型理由**（Tandem Match vs Bruene / Monimatch / 耦合线 / 对数检波…）见
[`docs/05` §3.2.1–§3.2.2](../../docs/05-hw-sw-interface-contract.md)（**V2 备选 = AD8307 对数检波**，用于微功率档精度或"免组合搜索"）。

## 4. 接口

- 射频输入：来自 `lpf-module`（SMA）
- 射频输出：至天线座（SMA）
- 继电器电源：**`+5 V`**（MP2315 降压轨；HK4100F-**DC5V**-SHG 线圈，6×40 mA）
- 控制：6 路经 **`CA-DV8008N`（I²C `0x28`）** 直接驱动（K1–K6；**不占用 ESP32 GPIO**）
- 反馈：SWR 前向/反射两路检波 → ADC；SWR>3.0 时固件禁止发射
- 引脚分配以 `docs/05-hw-sw-interface-contract.md` 为唯一权威来源

## 6. 验证要点

- **继电器插入损耗 <0.1dB @3.5–3.6MHz**。
- **隔离度 >40dB**。
- **100 次切换后接触电阻变化 <20mΩ**。
- **2.5W 连续 30 分钟后接触电阻漂移 <30mΩ**。
- **6 只继电器同时吸合电流**：🔴 **≈240 mA @ +5 V**（5 V 线圈，40 mA/只；~~<110 mA @12 V~~ 已废）。
- **CA-DV8008N 温升 / 关断反峰**：6 路中 1–2 路常通时的壳温，2.5 W 连续 30 分钟后 `<70 °C`；`OC1–OC6` 关断反峰 <25 V，且 **`COM` 已接 `+5 V`**。
- **1µF 电容反峰抑制实测反峰 <25V**（示波器）——**仅适用于更早的 2N7002 分立方案**（已废，见上）。
- ⚠️ **5 V 线圈动作时间未实测**：`HK4100F-DC5V-SHG` 的吸合/释放时间需真机复核（固件 Kconfig 仍按 5 ms/8 ms）。
- **T106-6 磁环表面温度 <70°C**（模拟 15-j2000Ω 负载，2.5W 连续 30 分钟）。
- 静态遍历：50Ω 负载下 ≥8 种组合 SWR<1.2；100/150Ω 与 10/20Ω 负载下各 ≥3 种组合 SWR<2.0。
- 模拟天线：120-j1050Ω 验证 33µH 档 SWR<2.5；50-j1110Ω 验证 47µH 档 SWR<1.8；88-j1030Ω 验证 45µH 档 SWR<2.0。
- 耦合器：耦合度 20±3dB，方向性 >25dB，带内平坦度 <1.0dB。
