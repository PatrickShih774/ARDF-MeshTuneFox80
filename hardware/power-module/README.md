# power-module 电源模块

## 1. 模块定位

整机电源模块，提供 4 路电压轨并负责电池管理与效率优化。以 MP2315 同步降压替代原 7805 LDO 方案（原方案效率约 68%，大电流发热严重），并为射频链路提供独立低噪声 3.3V 轨。

## 2. 关键指标

| 电压轨 | 方案 | 用途 |
|--------|------|------|
| 5V 主轨 | MP2315 同步降压 | 栅极偏置分压、控制电路 |
| 3.3V 射频轨 | MD7673 LDO | Si5351 本振（低噪声） |
| 3.3V 数字轨 | 独立 π 型 RC 滤波 | ESP32-C3、LCD、编码器 |
| 12V 功放轨 | 升压模块（PWM 可调） | BS170 漏极 12–13.8V、继电器线圈 |

| 项目 | 指标 |
|------|------|
| 电池 | 2S 500mAh（7.4V 标称） |
| 12V 轨纹波 | 2.5W 发射时峰峰值 <0.5V |
| 续航（连续发射 @2.5W） | 总电流约 0.800A，约 38 分钟 |
| 续航（竞赛模式，静默期释放继电器） | 总电流约 0.300A，约 100 分钟 |
| 续航（静默待机） | 总电流约 0.200A，约 150 分钟 |

## 3. 核心器件

- MP2315 同步降压 DC-DC（5V 主轨）
- MD7673（MD7673E50VC1）LDO（3.3V 射频轨）
- π 型 RC 滤波网络（含 100nF X7R），用于 3.3V 数字轨与本振独立滤波
- 3.7V→12V 升压模块（DC-DC，PWM 可调输出）
- 输入/输出电容套件：电解 + 钽 + 陶瓷
- 电池：2S 500mAh 锂电 + 电池座 + 保护/充电接口

## 4. 接口

- 输入：2S 电池（7.4V）
- 输出至 `core-board`：12V 功放轨、5V 主轨、3.3V 射频轨、3.3V 数字轨
- 控制：ESP32-C3 PWM → 升压模块反馈网络（功率档位 0.02–2.5W）
- 监测：电池电压 ADC（用于状态回传与低压告警）
- 引脚分配以 `docs/05-hw-sw-interface-contract.md` 为唯一权威来源

## 5. 目录内容

| 子目录 | 内容 |
|--------|------|
| `schematic/` | 电源原理图源文件（含 π 型滤波与升压反馈改造） |
| `pcb/` | 电源模块 PCB 源文件（大电流走线、散热铺铜） |
| `gerber/` | 制板 Gerber 包 |
| `bom/` | 物料清单（MP2315、MD7673、升压模块、电容、电池） |

> 本模块不含测试子目录；电源相关测试记录在 `pa-module/test/` 中登记。

## 6. 验证要点

- **2.5W 发射时 12V 轨纹波峰峰值 <0.5V**（示波器动态负载测试）。
- 各电压轨空载/满载电压精度与压降实测。
- 3.3V 射频轨噪声实测（对本振相噪的影响评估）。
- 升压模块 PWM 调压线性度：对照 12V→2.5W、5V→0.43W、3V→0.15W、2V→0.07W、1.5V→0.04W。
- 电池续航验证：对照 0.800A/0.400A/0.300A/0.200A 四档实测放电时间。
- 效率与温升：MP2315 与升压模块满载 30 分钟温升检查。
