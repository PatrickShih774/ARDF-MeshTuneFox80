# power-module 电源模块

## 1. 模块定位

整机电源模块，提供 4 路电压轨并负责电池管理与效率优化。以 MP2315 同步降压替代原 7805 LDO 方案（原方案效率约 68%，大电流发热严重），并为射频链路提供独立低噪声 3.3V 轨。

## 2. 关键指标

| 电压轨 | 方案 | 用途 |
|--------|------|------|
| **VCC（输入级）** | **2S 锂电直供 6.0–8.4V**（标称 7.4V）；❌ ~~兼容 12V~~ **已于 2026-10-11 取消**；**本项目不设升压** | ① 功放漏极（E 类按 **7.4V 标称定点**；满电 8.4V 输出 ≈3.22W —— ✅ **甲方案：接受、不降驱动**）② +5V 降压的输入 ③ vbat 检测分压 |
| 5V 主轨（DC-DC 第 2 级） | MP2315 同步降压（输入 4.5–24V ⇒ 2S 与 12V 都可） | **ATU 继电器线圈（6×40mA=240mA）**、栅极偏置分压、LCD 背光 |
| 3.3V 射频轨（LDO 第 3 级） | MD7673 LDO（由 5V 供电） | Si5351 本振（低噪声） |
| 3.3V 数字轨（LDO/滤波 第 3 级） | 独立 π 型 RC 滤波 | ESP32-C3、LCD、编码器、CA-DV8008（逻辑侧） |

| 项目 | 指标 |
|------|------|
| 电池 | 2S 500mAh（7.4V 标称，满电 8.4V，截止 6.0V） |
| 电源纹波 | 功放轨 = VCC 直供（**无开关纹波源**）；需实测 **5V / 3.3V 数字轨 <50mVpp** + 继电器吸合跌落 |
| 续航（连续发射 @2.5W，V_CC≥8.0V） | 总电流约 0.800A，约 38 分钟 |
| 续航（竞赛模式，静默期释放继电器） | 总电流约 0.300A，约 100 分钟 |
| 续航（静默待机） | 总电流约 0.200A，约 150 分钟 |

## 3. 核心器件

- MP2315 同步降压 DC-DC（5V 主轨）— ⚠️ 可选简化：改用**成品 2S→5V 降压模块**（省外围与 EMI 调试，见 [docs/04 §3.7.1](../../docs/04-hardware-architecture.md)）
- MD7673（MD7673E50VC1）LDO（3.3V 射频轨）
- π 型 RC 滤波网络（含 100nF X7R），用于 3.3V 数字轨与本振独立滤波
- ⚠️ **升压模块已于 2026-10-11 删除**（本项目不设升压）
- 输入/输出电容套件：电解 + 钽 + 陶瓷
- 电池：2S 500mAh 锂电 + 电池座 + 保护/充电接口（2S BMS + 8.4V 恒压充电）
- 🟠 **输入级保护与电源路径**（OR-ing / 反接 / TVS / PTC）**待定** — 见 [docs/04 §3.7.3](../../docs/04-hardware-architecture.md) 与 `docs/05` §7 #7e

## 4. 接口

- 输入：**2S 电池（6.0–8.4V，标称 7.4V）**；❌ ~~兼容 12V 外部输入~~ **（2026-10-11 取消）**；充电 = **成品 2S 充电模块**（8.4V CC/CV，如 TP5100）+ 2S BMS 保护板 — `docs/05` §7 #8
- 输出至 `core-board`：**VCC**、5V 主轨、3.3V 射频轨、3.3V 数字轨
- 控制：~~ESP32-C3 PWM → 升压模块反馈网络~~ ❌ 作废（无升压）；`PA_PWR_PWM`(GPIO12) 去向待定 — `docs/05` §7 #7a
- 监测：电池电压 ADC（分压 **30k/9.1k/1k**，满量程 14.18V；🟠 12V 取消后 22k 亦够用，保留 30k 仅为留余量/未来 3S 铁锂 — `docs/05` §7 #7d）
- 引脚分配以 `docs/05-hw-sw-interface-contract.md` 为唯一权威来源

## 6. 验证要点

- **2.5W 发射时 12V 轨纹波峰峰值 <0.5V**（示波器动态负载测试）。
- 各电压轨空载/满载电压精度与压降实测。
- 3.3V 射频轨噪声实测（对本振相噪的影响评估）。
- 升压模块 PWM 调压线性度：对照 12V→2.5W、5V→0.43W、3V→0.15W、2V→0.07W、1.5V→0.04W。
- 电池续航验证：对照 0.800A/0.400A/0.300A/0.200A 四档实测放电时间。
- 效率与温升：MP2315 与升压模块满载 30 分钟温升检查。
