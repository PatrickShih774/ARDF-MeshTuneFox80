# interconnect 模块互联定义

## 1. 模块定位

模块间连接器定义与线束设计的唯一集中区。统一登记射频 SMA 互联、排针排母信号定义、电源轨分配、线束走向与线径选型，避免同一信号在不同模块文档中出现不一致描述。

## 2. 关键指标

| 项目 | 要求 |
|------|------|
| 射频连接 | SMA 母座（底板 3 个 + 模块 6 个），50Ω |
| 射频跳线 | SMA 公-公短线 ×3 |
| 控制/电源连接 | 2.54mm 排针排母 |
| 信号链 | Si5351 → PA → LPF → ATU → ANT |
| 电源轨 | 12V 功放 / 5V 主 / 3.3V 射频 / 3.3V 数字（独立走线） |
| 天线座 | 独立天线座 + 电池座 |

## 3. 核心器件

- SMA 母座 ×9（底板 3 + 模块 6）、SMA 公-公短线 ×3
- 2.54mm 排针/排母（各模块插座）
- 天线座、电池座
- 线束材料：多股软铜线、杜邦线、热缩管、扎带
- 可选：屏蔽线（SWR 检波模拟信号、Si5351 I²C 长距离走线）

## 4. 接口

本目录定义以下接口清单（**引脚分配以 `docs/05-hw-sw-interface-contract.md` 为唯一权威来源**）：

| 接口 | 内容 |
|------|------|
| RF-PA-IN | Si5351 输出 → PA 输入（SMA） |
| RF-PA-OUT | PA 输出 → LPF 输入（SMA） |
| RF-LPF-OUT | LPF 输出 → ATU 输入（SMA） |
| RF-ANT | ATU 输出 → 天线座（SMA） |
| PWR-12V | 升压模块 → PA 漏极、ATU 继电器线圈 |
| PWR-5V | MP2315 → 偏置分压、控制电路 |
| PWR-3V3-RF | MD7673 → Si5351（低噪声独立轨） |
| PWR-3V3-DIG | π 型 RC 滤波 → ESP32-C3、LCD、编码器 |
| CTRL-GPIO | 键控、6 路继电器驱动、LCD、编码器、按键、蜂鸣器 |
| ADC-SWR | SWR 前向/反射检波电压 |
| BUS-I2C | ESP32-C3 ↔ Si5351 |

## 5. 目录内容

| 子目录 | 内容 |
|--------|------|
| `connector/` | 连接器针脚定义表（SMA 针脚定义、排针排母逐脚定义、电源轨接线表） |
| `harness/` | 线束图（走向、长度、线径、颜色约定、压接方式、屏蔽处理） |

## 6. 验证要点

- **连接器插拔寿命**：排针排母与 SMA 反复插拔后的接触可靠性。
- **SMA 力矩**：按规格拧紧后插损与阻抗连续性，避免过紧损伤 PCB 焊盘。
- **线束压降**：12V 功放轨与 5V 主轨在峰值电流下的导线压降实测，确认在允许范围内。
- 模拟信号抗干扰：SWR 检波线束走线对读数稳定性的影响（重复测量 10 次 SWR 标准差 <0.15）。
- 线束机械可靠性：现场悬挂与搬运状态下的防拉扯与固定检查。
