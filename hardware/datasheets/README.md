# datasheets 器件数据手册归档

## 1. 本目录定位

器件数据手册（Datasheet）的归档与索引区。为硬件设计、验证与替代选型提供统一可追溯的器件参数来源。**PDF 本体不入 git**，本目录只保存归档规范与索引文件。

## 2. 归档规范

**文件名格式**：`<器件型号>_<厂商>_<文档类型>.pdf`

示例：

```
2N7002_onsemi_datasheet.pdf
HK4100F-DC-12V_huike_datasheet.pdf
MP2315_mps_datasheet.pdf
ESP32-C3_espressif_datasheet.pdf
```

**归档方式**：

- PDF 体积大且受 `.gitignore` 限制，采用 **外部归档 + 索引登记** 的方式。
- 外部归档位置（团队网盘/对象存储）统一登记。
- 在本目录 `INDEX.md` 中登记每个文档的：器件型号、厂商、文档类型、版本/日期、外部归档路径、**文件哈希（SHA-256）**、获取日期。
- 器件停产或文档改版时，保留旧版本哈希记录，新增新版本条目，不覆盖历史。

**INDEX.md 字段建议**：

| 字段 | 说明 |
|------|------|
| 器件型号 | 与 BOM 中型号一致 |
| 厂商 | 原厂名称 |
| 文档类型 | datasheet / application note / errata / 选型手册 |
| 版本/日期 | 文档版本号或发布日期 |
| 外部归档路径 | 团队归档位置 |
| SHA-256 | 文件哈希，校验完整性 |
| 获取日期 | 下载/归档日期 |

## 4. 目录内容

| 路径 | 内容 |
|------|------|
| `README.md` | 本文件（归档规范与器件清单） |
| `.gitkeep` | 占位文件（保持空目录入版本库） |
| `INDEX.md` | 外部归档索引（登记版本与哈希），创建后置于本目录 |

## 5. 验证要点

- 每条索引条目的 SHA-256 与实际归档文件一致。
- BOM 中的型号与本清单、`INDEX.md` 三者一致。
- 关键参数摘录（耐压、电流、热阻）与设计取值一致，例如 BS170 的 R_θJA=150°C/W、HK4100F 线圈电阻 720Ω、2N7002 的 Vdss=60V。
