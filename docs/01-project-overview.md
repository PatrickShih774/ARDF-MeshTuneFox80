# 01 · 项目概述

> 状态：已建立｜适用版本：V3.7｜权威性：概述性（技术指标以 [00-项目升级计划书](00-project-upgrade-plan.md) 为准）

---

## 1. 项目定位

**ARDF-MeshTuneFox80** 是一款基于 **ESP32-C3** 的开源 **80 米波段（3.5–3.6 MHz）ARDF 无线电测向信号源**。

它源自开源工程基座 **ARDF_80M_3.5MHZ**（立创开源平台，原版复刻成本 57.8 元），在其基础上做三项关键升级：

| 升级方向 | 原项目痛点 | 本项目方案 |
|---------|-----------|-----------|
| **功率与效率** | 约 1 W 输出勉强满足短距离；7805 LDO 效率约 68%、发热严重 | 3× BS170 并联 E 类功放 1–2.5 W；MP2315 同步降压 + 独立 LDO 供电 |
| **天线匹配** | 80 m 短导线呈高电抗低辐射电阻，无匹配网络时发射效率极低 | 6 继电器 L 型自动天调（ATU），64 种组合，算法借鉴 N7DDC ATU-100 |
| **多机协同** | 无多机同步机制，各台靠人工校时 | ESP-NOW 主从时钟同步 + 单跳中继 Mesh 容错 |

此外补齐原项目未完成的 **CW 自动拍发**（A1A，10–12 WPM）与 **六种竞赛模式**全覆盖。

---

## 2. 项目基因

```
ARDF（运动） + Mesh（ESP-NOW 多机网络） + Tune（自动调谐 ATU） + Fox（猎狐） + 80（80 米波段）
```

两个创新点（**Mesh**、**Tune**）+ 项目基因（**ARDF**、**Fox**）一目了然。

## 4. 竞赛模式覆盖

《业余无线电测向竞赛规则》（2019 版）中与信号源发射直接相关的竞赛项目共 **6 种**，本项目全覆盖：

| # | 竞赛项目 | 关键约束 | 固件模式 |
|---|---------|---------|---------|
| 1 | 标准距离无线电测向 | 3.550 MHz 统一频率；1–2 W；5 分钟周期每台 1 分钟；识别码 MOE–MO5；结束前 2 秒 1 kHz 长音 | `MODE_STANDARD` |
| 2 | 短距离无线电测向 | 各台频率不同（3.500–3.590 MHz，11 频点）；0.1–0.5 W；连续发射；MO+单数字 | `MODE_SHORT_DISTANCE` |
| 3 | 快速无线电测向 | 1 分钟周期每台 12 秒；慢速区 3.51 MHz / 快速区 3.57 MHz；0.1–0.5 W | `MODE_FAST` |
| 4 | 定向猎狐 | 隐蔽台 0.02–0.1 W、信标台 1–2 W；连续发射；射频覆盖 30 m 可听 / 250 m 不可听 | `MODE_FOXORING` |
| 5 | 阳光测向 | 0.02–0.1 W；连续发射；电台间距 ≥15 m | `MODE_SUNSHINE` |
| 6 | 短距离定向猎狐 | 隐蔽台 0.02–0.1 W、信标 0.1–0.5 W；字母编号 AA–OO；频率赛前公布 | `MODE_SHORT_FOXORING` |

## 5. 关键设计指标

### 5.1 射频链路

| 指标 | 数值 |
|------|------|
| 频率范围 | 3.5–3.6 MHz，100 Hz 步进 |
| 频率稳定度 | ≤50×10⁻⁶（Si5351 晶振 ±20–50 ppm） |
| 调制方式 | **A1A**（键控无调制载波），软起软降 2–5 ms |
| 码速 | 10–12 WPM（误差 <2%） |
| 额定输出功率 | 1–2.5 W（3× BS170 并联 E 类） |
| 峰值短时功率 | 3.5 W（限时 ≤30 s，需散热片） |
| 低功率档 | 0.02–0.5 W（PWM 调升压模块输出电压） |
| 漏极电压 | 12–13.8 V |
| 栅极偏置 | ≈2.1 V 直流（10 kΩ + 2.2 kΩ 分压 + NTC 温度补偿 + BZX84-C10 保护） |
| 效率 | 60%–73% |
| 谐波抑制 | 三阶椭圆低通，2f₀（7.1 MHz）衰减 ≥55 dB |
| 安全联锁 | SWR > 3.0 禁止发射 |

### 5.2 ATU 匹配网络

| 项 | 数值 |
|----|------|
| 拓扑 | L 型，3 电感 + 3 电容，**64 种组合** |
| 电感 | L1 = 12 µH（T37-6，约 63 圈）/ L2 = 33 µH（T106-6，约 53 圈）/ L3 = 47 µH（T106-6，约 64 圈） |
| 电容 | 22 / 120 / 330 pF，**NP0 1206/1812，耐压 ≥630 V**（谐振高压可达 816 Vrms） |
| 继电器 | HK4100F-DC-12V，SPDT，3 A @ 250 VAC，线圈 720 Ω / 16.7 mA，吸合 6 ms / 释放 4 ms |
| 驱动 | 2N7002 + 100 Ω 栅极电阻 + 10 kΩ 下拉 + 1 µF 陶瓷电容反峰抑制（可并联 1N4148 冗余） |
| 负载覆盖（挂树） | R≈120 Ω / X≈-1050 Ω → 需串联电感 30–34 µH、并联电容 ≈25 pF |
| 负载覆盖（实验室） | R≈50–88 Ω / X≈-1100 Ω → 需串联电感 35–50 µH、并联电容 0–450 pF |
| 调谐时间 | 粗调+细调 2–4 秒；全遍历约 5 秒；NVS 微调 <0.5 秒 |
| 调谐成功率 | >95% |

### 5.3 组网与同步

| 项 | 数值 |
|----|------|
| 链路 | ESP-NOW（原生 CCMP 加密）+ 应用层 HMAC-SHA256 |
| 安全 | MAC 白名单 + 序列号防重放 |
| 同步周期 | 每 5 分钟重同步；底板保留 32.768 kHz 晶振 DNP 焊盘 |
| Mesh | 单跳中继容错（仅支持 2 跳） |
| 通信距离 | 开阔地 100 m；密林 30–50 m |
| 帧排队 | 发射窗口内收到的同步帧入队列，发射结束后处理 |

### 5.4 电源与续航（2S 500 mAh）

| 工作模式 | 功放 | 控制 | ATU 继电器 | 总电流 | 续航 |
|----------|------|------|-----------|--------|------|
| 连续发射 @2.5 W | 0.5 A | 0.2 A | 0.100 A | 0.800 A | ≈38 分钟 |
| 竞赛模式（1/5 占空比，继电器持续吸合） | 0.1 A | 0.2 A | 0.100 A | 0.400 A | ≈75 分钟 |
| 竞赛模式（静默期释放继电器） | 0.1 A | 0.2 A | 0 A | 0.300 A | **≈100 分钟** |
| 静默待机（继电器释放） | 0 | 0.2 A | 0 A | 0.200 A | ≈150 分钟 |

## 6. 项目边界

### 6.1 本项目做什么

- 80 米波段 ARDF 竞赛信号源的**完整软硬件开源方案**：主板、功放模块、低通模块、ATU 模块、主控交互模块、电源模块。
- 支持 6 种竞赛模式的**固件**（ESP-IDF / ESP32-C3）。
- **多机联动**（ESP-NOW Mesh）与**中控 PC 软件**。
- **十阶段专项验证方案**与实测报告。

### 6.2 本项目不做什么

- ❌ **不参与竞赛规则制定**，仅按《业余无线电测向竞赛规则》（2019 版）实现。
- ❌ **不提供发射许可**。使用者须持有相应业余无线电操作证书并办理设台手续。
- ❌ **不做 2 米波段**。`ARDF_2M_144MHz` 是并行启动的独立项目（见项目升级计划书 第九章），不在本仓库范围。
- ❌ **不做天线设计优化**。本项目仅配套 5 m 垂直导线 + 5 m 地线的**部署规范**与匹配方案，不研究天线本体。
- ❌ **不提供闭源算法源码**。ATU 调谐算法与 Mesh 路由算法的商业闭源版本不在本仓库（见 [ADR-0006](adr/ADR-0006-layered-licensing-gpl-isolation.md)）；本仓库内为其**开源参考实现**。

### 6.3 合规边界

| 场景 | 要求 |
|------|------|
| 持证火腿自用 | 合法 |
| 未组装套件销售 | 通常不视为无线电发射设备整机；建议明示"组装后使用需持证并办理设台手续" |
| 成品整机对公销售 | **需要 SRRC 型号核准** |
| 教学仪器类目 | 监管实践中通常按器材销售，但法律层面无明文豁免；销售前应与当地无线电管理机构预沟通 |

详见 [docs/08-licensing-and-compliance.md](08-licensing-and-compliance.md)。
