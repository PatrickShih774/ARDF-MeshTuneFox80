# ADR-0009：ATU 匹配网络定稿为「③ 串 C 并 L」+ 单磁环双抽头（4C+2L）

- **状态**：✅ Accepted（2026-10-11）
- **取代**：ADR-0003（6 继电器 L 型网络：**串联 L 旁路 + 并联 C**，64 组合）— 该方案基于"设计估算"，**未用实测数据验证** ✗
- **相关**：[`hardware/antenna/test/2026-10-field-measurements.md`](../../hardware/antenna/test/2026-10-field-measurements.md)（11 点实测）· `docs/04` §3 · `docs/05` §2.4/§3.2

## 背景

用户实测两组天线阻抗（5 m 导线 + 5 m 地线，全部容性）：

| 场景 | 点数 | R 范围 | X 范围 | ③ 所需串 C | ③ 所需并 L |
|---|---|---|---|---|---|
| **野外挂树** | 6 | 115.1–134.4 Ω | −1180…−991 Ω | 57.49–70.64 pF（1.23×）| 17.55–21.18 µH（1.21×）|
| 实验室室内 | 5 | 48.9–87.8 Ω | −1110…−1030 Ω | 39.95–57.57 pF | 19.99–25.07 µH |
| **合计** | 11 | — | — | **39.95–70.64 pF（1.77×）** | **17.55–25.07 µH（1.43×）** |

**关键发现**：串联 C 是**敏感维度**（负责抵消电抗，偏差直接留残余电抗 ✗），并联 L 不敏感（固定一只时野外最差也只到 1.38 ✓）⇒ **档位预算应优先给电容** ✓。

**方案实算对比**（1 只 T68-6 磁环出抽头提供 L，L ∝ N²）：

| 方案 | 野外 6 点最差 SWR | 室内外 11 点最差 SWR |
|---|---|---|
| 3C+3L（C 100/180/220 · 57/59/67 匝）| 1.26 ✓ | 1.92 ✗ |
| **4C+2L（C 68/390/470/1000 · 59/63 匝）** | **1.32** ✓ | **1.55** ✓ |
| 5C+1L（C 100/220/270/330/560 · 58 匝）| 1.38 ✓ | —（L 固定 ✗）|

## 决定

**采用 ③ 串 C 并 L（负载侧）+ 4C+2L，共 6 只继电器：**

```
RF_IN ──[ 串联 C 组 ]──●── 天线
                       │
                    [ 并联 L ]（单只 T68-6 双抽头）
                       │
                      GND
```

| 元件 | 取值 | 继电器 |
|---|---|---|
| **串联电容**（4 只，逐只旁路 ⇒ 串联组合 = 调和和）| **68 / 390 / 470 / 1000 pF**，630 V NP0 | K1–K4（旁路型，NO）|
| **并联电感**（1 只 T68-6，抽头选择）| 绕 **63 匝**，抽头 **59 / 63 匝** ⇒ **19.8 / 22.6 µH** | K5（59 匝）· K6（63 匝），NO |
| 全不吸合 | 电容全旁路 + 电感全断开 | **直通** ✓（与固件 `mask=0` 一致 ✓）|

- **组合数**：4C（16 态）× 2L（3 态：无 / 19.8 / 22.6 µH）= **48 组合**
- **驱动**：CA-DV8008N（I²C `0x28`）用 **OC1–OC6**，OC7/OC8 备用 ✓
- **继电器**：HK4100F-DC5V-SHG（5 V 线圈，+5 V 轨，6×40 mA = 240 mA）

## 后果

1. **性能**：野外 6 点最差 SWR **1.32** ✓；室内最差 **1.55** ✓（仍可发射，SWR>3 保护不动作 ✓）
2. **硬件**：旧 3 只电感（12/33/47 µH）→ **1 只 T68-6 双抽头线圈** ✓（省 2 个大磁芯 + 板面积 ✓）；继电器仍 6 只 ✓
3. **固件契约变更**：`relay_mask` 位定义**重排**（K1–K4 = 电容旁路、K5/K6 = 电感抽头 ✓）；`ATU_MATCH_SAFE_COMBO = 0`（全释放 = 直通）**保持不变** ✓✓
4. **文档**：`relay-wiring.md` 的 64 组合表 ✗ → **48 组合表** ✓；BOM 删 `L1/L2/L3`、加 `L_tap` ✓；`docs/04` §3、`docs/05` §2.4/§3.2 同步 ✓
5. **待补**：#1 测量频率与架设高度未记录 ✗；#2 磁环抽头（59/63 匝）需 NanoVNA 实测并按实测微调 ✗

## 为什么不是 3C+3L

3C+3L 的野外精度略好（1.26 vs 1.32，差 0.06 无感 ✓），但**室内会劣化到 1.92** ✗ —— 因为它只有 3 只电容、C 阶梯太粗 ✗。本项目"以野外为主、室内仅调试用"，但 1.92 已经影响室内可用性 ⇒ 选 4C+2L ✓。

## 为什么不是 5C+1L

L 固定 ⇒ 室内所需的 24.9–25.1 µH 与野外所需的 17.6–21.2 µH **无法兼顾** ✗（跨度 1.43×）；单只 L 在野外虽只到 1.38 ✓，但没有余量应对架设变化 ✗。

---

**附：组合表生成规则**（供固件与文档同步）

- 电容组合（串联）：`1/C_tot = Σ 1/C_i`（i ∈ 旁路的**未**旁路器）⇒ 可实现 ≈ 68 / 68∥390=57.8 / 68∥470=59.4 / 390∥470… 等 16 态（含全旁路 = 直通）
- 电感组合：K5/K6 均为 **NO**，二者不同时闭合 ⇒ L ∈ {断开, 19.8, 22.6} µH
- 每只电感抽头**不可并联使用**（同磁环磁耦合 ⇒ 并联等于短路线段 ✗）
