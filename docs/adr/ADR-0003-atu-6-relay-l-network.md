# ADR-0003 ATU 采用 6 继电器 L 型匹配网络

- 状态：已接受
- 日期：2026-09
- 决策者：射频组 / 硬件组

## 背景

5m 短导线在 3.5MHz 上表现为**高电抗、低辐射电阻**，是典型的"难匹配"负载。
实测数据（见 `validation/stage-0-rf-frontend/`）：

| 场景 | 实测阻抗 | 匹配需求 |
| --- | --- | --- |
| 挂树 | R≈120Ω，X≈-1050Ω | 串联电感 **30–34µH**，并联电容约 **25pF** |
| 实验室 | R≈50–88Ω，X≈-1100Ω | 电感 **35–50µH**，电容 **0–450pF** |

由此反推匹配网络的**覆盖范围要求**：

- 串联电感需覆盖 **0–92µH**；
- 并联电容需覆盖 **0–472pF**；
- 需要考虑电阻在 **115–135Ω** 范围内的扫动。

同时项目有明确的成本、体积与续航约束（便携式测向信号源）。

## 决策

采用 **6 只 HK4100F-DC-12V 构成 L 型可切换匹配网络**：

- **电感**：L1 = 12µH（T37-6）、L2 = 33µH（T106-6）、L3 = 47µH（T106-6）；
- **电容**：22 / 120 / 330pF（NP0，耐压 ≥630V）；
- **组合数**：6 位开关 → **64 种组合**，覆盖 0–92µH 与 0–472pF；
- **驱动**：2N7002 N-MOS 驱动 + **1µF 反峰抑制电容**；
- **算法**：借鉴 N7DDC ATU-100 的**粗调 + 细调 + 全遍历兜底**三级策略，
  调谐结果写入 NVS 以便下次微调（目标：首次 <5s，NVS 微调 <0.5s）。

## 后果

**正向**

- 覆盖全部实测负载（挂树、实验室、边界阻抗），见 `validation/stage-2-matching-network/` 判据。
- 成本低：继电器约 **2 元/只**，L/C 均为常规元件。
- 算法成熟、可解释，全遍历兜底保证极端负载下仍能收敛。
- 拓扑简单，寄生参数可控，插入损耗预算可达 <0.1dB。

**负向**

- 继电器机械寿命有限：**电气 10 万次 / 机械 1000 万次**，需在算法中控制动作次数。
- 切换时间约 **6ms**，静默期必须为此留出时间。
- 占板面积约 **55×65mm**，是模块中最大的一块。
- 线圈持续通电极耗电；**静默期应释放继电器省电**，预计续航由 **75 分钟提升到约 100 分钟**，
  代价是每次唤醒需重新吸合（时间已计入调谐预算）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 双稳态继电器（ATU-10 的 IM41） | 拒绝：省电优势明显但成本高，超出当前 BOM 预算 |
| 变容二极管 | 拒绝：耐压不足，谐振点高压下有击穿风险 |
| PIN 二极管 | 拒绝：射频性能可接受但成本高、驱动复杂 |
| 伺服可变电容 | 拒绝：体积大、机械结构复杂、成本高 |
