## 一、项目概况

### 1.1 项目背景

**ARDF-MeshTuneFox80** 是一款基于ESP32-C3单片机的开源80米波（3.5–3.6MHz）无线电测向信号源，原版复刻成本57.8元。其核心目标是解决商业化ARDF信号源“体积庞大、技术老旧、缺乏智能化”的痛点，为业余无线电“猎狐”运动提供现代化、可编程、可联网的硬件方案。

ARDF运动俗称“无线电猎狐”，国际业余无线电联盟将80米波段（3.5–3.6 MHz）列为标准竞赛频段。根据《业余无线电测向竞赛规则》（2019版），与信号源发射直接相关的竞赛项目共**6种**：标准距离、短距离、快速测向、定向猎狐、阳光测向、短距离定向猎狐。

### 1.2 原项目系统架构

| 模块 | 器件/方案 | 功能说明 |
|------|-----------|----------|
| 主控 | ESP32-C3 | 逻辑控制、WiFi校时、屏幕驱动 |
| 本振 | Si5351 | 可编程PLL，3.5–3.6MHz输出，100Hz步进 |
| 功放 | S2SK3476 AB类 | 目标输出功率≥1W |
| 滤波 | 三阶椭圆低通 | 中心频率3.55MHz，2f₀处衰减≥55dB |
| 交互 | 12864 LCD + EC11编码器 + 双按键 | 菜单操作、参数调节 |
| 电源 | 2S锂电 + 7805 LDO | 7.4V供电，5V稳压输出 |

### 1.3 原项目核心功能

- 多工作模式：连续模式、计时模式、测试模式、CW发射模式（待优化）、CW听抄练习模式（待优化）
- 频率设置：3.5MHz–3.6MHz范围内精确设置发射频率
- 联网能力：支持WiFi配置、NTP校时，内置RTC时钟
- 人机交互：12864液晶屏显示台号、频率、工作模式


## 二、原项目优缺点分析

### 2.1 优势

**（1）成本优势显著。** 复刻成本仅57.8元，远低于商业产品（T3500PMF约288元）。

**（2）技术架构先进。** ESP32C3+Si5351的现代芯片组合替代传统分立架构，支持100Hz步进。

**（3）智能化功能丰富。** 12864液晶屏、旋转编码器和WiFi联网能力，支持NTP校时和远程参数下发。

**（4）扩展潜力大。** 预留CW电键接口和音频输入通道。

**（5）开源生态友好。** 代码和硬件设计文档完全开放。

### 2.2 不足

**（1）CW自动拍发功能未完成。** ARDF竞赛要求发射机连续自动拍发等幅电报，每个台号需发射独特识别码。

**（2）功率储备不足。** 当前约1W输出勉强满足短距离要求，但低于标准距离1–2W的典型值。

**（3）电源方案效率偏低。** 7805 LDO效率约68%，大电流时耗散功率大、发热严重。

**（4）缺乏多机同步机制。** 当前未实现多台信号源之间的时间同步。

**（5）天线系统未配套。** 80米波段短导线天线的输入阻抗呈高电抗、低辐射电阻特性，若无匹配网络，发射效率极低。


## 三、升级方案

### 3.1 功放模块升级：3个BS170并联E类方案

#### 3.1.1 功率能力

BS170三管并联总耗散能力约1.05–2.5W。

| 参数 | 修正值 | 说明 |
|------|--------|------|
| 额定输出功率 | **1–2.5W** | 长期安全运行 |
| 峰值短时功率 | **3.5W** | 限时≤30秒，需散热片 |
| 低功率档 | **0.02–0.5W** | 通过PWM调节升压模块输出电压实现 |
| 漏极电压 | 12–13.8V | 提高漏压可增加输出功率 |
| 栅极偏置 | ~2.1V直流 | 使管子工作在开关状态 |
| 效率 | 60%–73% | |

**若需5W输出**，必须换用**IRF510**（TO-220封装，Pd=20W，成本仅多1元）。

#### 3.1.2 微功率档实现方案

采用**PWM动态调节升压模块输出电压**。E类功放输出功率近似正比于 \( V_{dd}^2 \)：

| 升压模块输出 | 漏极电压 | 预估输出功率 |
|-------------|---------|-------------|
| 12V | 12V | 2.5W |
| 5V | 5V | 约0.43W |
| 3V | 3V | 约0.15W |
| 2V | 2V | 约0.07W |
| 1.5V | 1.5V | 约0.04W |

通过ESP32-C3的PWM控制升压模块反馈网络，可在保持E类开关状态不变的前提下，实现0.04–2.5W的功率调节。

#### 3.1.3 偏置电路

- 分压电阻：10kΩ + 2.2kΩ，从5V LDO分压得到约2.1V
- ~~温度补偿：分压电阻下端串联NTC热敏电阻（10kΩ B=3950）~~ → **已于 2026-09-26 取消**：
  改为**纯固定偏置**。12 个可用 GPIO 已全部用满、ADC1 无空闲通道可分配给 NTC，
  固件无法读温；代价是失去功放温度保护，详见
  [docs/17 §12.5](17-gpio-allocation-audit.md)
- 旁路电容：100nF陶瓷电容
- 栅极保护：10V双向稳压二极管（如BZX84-C10）

#### 3.1.4 散热设计

BS170数据手册标称 \( R_{\theta JA} = 150°C/W \)。

- 每管功耗约0.5W，\( \Delta T = 0.5W \times 150°C/W = 75°C \)
- 45°C环境下结温 = 45 + 75 = **120°C**，余量仅30°C
- 阶段测试增加热电偶实测TO-92壳温（2.5W连续发射30分钟，判定壳温<85°C）
- 若实测超限，将额定功率下调至**2W**，或预留IRF510兼容焊盘

**驱动电路：2N7002 + 1μF陶瓷电容**

```
ESP32-C3 GPIO ──100Ω──► 2N7002 栅极(G)
                         │
                       10kΩ
                         │
                        GND
2N7002 源极(S) ──► GND
2N7002 漏极(D) ──► 继电器线圈 ──► +12V
                    │
                   1μF 陶瓷电容（跨接线圈，限制反电动势）
```

**关键设计要点**：
- 2N7002在3.3V GPIO下，Rds(on)约1.6–4.5Ω，16.7mA线圈电流下压降仅0.03–0.08V，继电器吸合可靠。
- **100Ω栅极电阻**抑制振铃；**10kΩ下拉电阻**确保关断。
- **1μF陶瓷电容**跨接线圈，将反峰电压限制在约20V，2N7002 Vdss=60V，安全裕量充足。
- 可**同时保留1N4148续流二极管**作为冗余保护，两者并联不冲突。

**组合数**：6只继电器（3电感+3电容），**64种组合**。

#### 3.2.5 SWR检测

**Tandem Match定向耦合器结构**：

- **T1（电流互感器）** ：射频主线穿过磁环（1匝初级），次级10匝，采样主线电流。
- **T2（电压互感器）** ：主线上经串联限流电阻 \( R_{sense} \) 到地的支路穿过T2磁环，次级10匝，感应电压正比于线路电压。
- **耦合度**：20dB。
- **\( R_{sense} \)**：初始值1kΩ，用NanoVNA微调。
- **磁环**：FT37-43。
- **检波二极管**：1N5711与HSMS-2850并行对照。

#### 3.2.6 调谐算法（借鉴ATU-100）

1. **粗调（Grundmatch）** ：快速扫描预定义搜索表，找到SWR相对较低的起点。
2. **细调（Feinabstimmung）** ：从起点开始，采用坐标下降法，每次只改变一个继电器状态，测量SWR，保留改善方向，直到无法通过单个参数改变获得更好SWR。
3. **全局保护**：若细调后SWR仍>2.0，则全遍历64组，取全局最优。
4. **NVS存储**：调谐成功后保存最佳组合，下次开机直接加载，微调<0.5秒。
5. **低功率探测**：E类功放+ATU搜索采用低功率探测扫点，避免满功率遍历导致BS170击穿。

**调谐时间**：粗调+细调约**2–4秒**，全遍历约5秒。

#### 3.2.7 天线静电泄放

ATU输入端增加**1kV高压电阻**（100kΩ）到地，或射频专用GDT。

### 3.3 多机联动方案（ESP-NOW Mesh）

#### 3.3.2 时钟精度

依托每5分钟ESP-NOW重同步，内部RC可满足需求。底板保留32.768kHz晶振DNP焊盘。

## 四、天线系统部署要求

| 项目 | 要求 |
|------|------|
| 天线长度 | **5米**（推荐），最小4米，最大8米 |
| 地线 | **至少5米**，推荐3段×2米辐射状铺设 |

- 43材质磁环在3.5MHz的μ''值测量。

## 十一、商业化可行性与方案

### 11.1 合规路径

- **ARDF信号源属于业余电台专用设备**，持证火腿使用完全合法。
- **未组装套件通常不视为无线电发射设备整机**，但建议明示“组装后使用需持证并办理设台手续”。
- **成品整机对公销售：需要SRRC**。
- **教学仪器类目**：监管实践中通常按器材销售，但法律层面无明文豁免。需在销售前与当地无线电管理机构预沟通。

### 11.2 产品策略

| 产品线 | 内容 | 定价 |
|--------|------|------|
| DIY套件 | PCB+核心元器件+固件 | 169–219元 |

### 11.3 差异化卖点

- **多机联动与自适应Mesh容错**：ESP-NOW无线自动同步，从机间Mesh中继容错。
- **ATU自动调谐**：借鉴ATU-100成熟算法，6继电器L型匹配，覆盖5–8m短导线。
- **开源生态**：允许二次开发，可作为电子设计教学平台。
- **中控PC软件**：实时监控所有从机状态，支持远程参数下发和赛事编排。

## 十三、总结

**ARDF-MeshTuneFox80**（狐网天调80）V3.7版本基于V3.6，仅更新项目名称。核心技术与V3.6一致：

- **功放**：3个BS170并联E类方案，1–2.5W可调，微功率档PWM调压。
- **ATU**：6继电器（HK4100F-DC-12V）L型匹配，电感12/33/47µH，电容22/120/330pF，64种组合。
- **驱动**：2N7002 + 1μF陶瓷电容，借鉴ATU-100成熟方案。
- **调谐算法**：借鉴ATU-100爬山搜索（粗调+细调）。
- **多机联动**：ESP-NOW + Mesh中继容错，HMAC-SHA256安全认证。
- **电源**：MP2315 + MD7673 + 升压模块（PWM可调）。
- **竞赛模式**：6种全覆盖，识别码按规则原文修正。
- **成本**：单套BOM **129.30元**（不含电池），含电池**155.20元**。量产优化后约**115–125元**。

本项目可作为正式ARDF竞赛信号源，覆盖国内各级赛事全部6种与信号源发射相关的竞赛项目。
