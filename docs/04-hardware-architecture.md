# 04 · 硬件架构

> 状态：已建立｜适用版本：V3.7｜权威性：**★ 唯一权威**（硬件模块划分与互联）
> 硬件许可证：**CERN-OHL-S v2**

---

## 1. 架构总原则

整机采用 **「核心底板 + 可插拔射频模块」** 架构：

```
┌───────────────────────────────────────────────────────────────┐
│                    核心底板 core-board                         │
│                    130 × 95 mm  四层板                         │
│                                                               │
│   ┌────────────┐  ┌────────────┐  ┌────────────┐             │
│   │ mcu-ui-    │  │ power-     │  │ lpf-       │             │
│   │ module     │  │ module     │  │ module     │             │
│   │ (插座)     │  │ (插座)     │  │ (插座)     │             │
│   └────────────┘  └────────────┘  └────────────┘             │
│                                                               │
│   ┌────────────┐  ┌────────────┐                              │
│   │ pa-module  │  │ atu-module │   SMA 互联 + 排针互联         │
│   │ (插座)     │  │ (插座)     │                              │
│   └────────────┘  └────────────┘                              │
└───────────────────────────────────────────────────────────────┘
```

**为什么模块化**

| 收益 | 说明 |
|------|------|
| 独立迭代 | 射频模块可单独改版，不必重投整板 |
| 分级调试 | 按 ATU 专项验证方案逐模块验证（见 [validation/](../validation/README.md)） |
| 成本控制 | 功放管、继电器等易损件可单独更换 |
| 扩展性 | 未来替换为 IRF510 版本（5 W）只需改功放模块 |
| 风险隔离 | 功放击穿不波及主控 |

**代价**：连接器引入插损与可靠性风险、体积增大、BOM 项增多。连接器规格必须在 `hardware/interconnect/` 中定义并做插拔寿命验证。

## 3. 各模块设计要点

### 3.1 核心底板 `core-board`

- **四层板**：信号 / 地 / 电源 / 信号，地平面完整。
- **尺寸**：130 × 95 mm。
- **承载**：各模块插座的机械与电气互联、电池座、天线座、SMA 转接。
- **接地策略**（关键）：射频地与大电流功放地**单点汇集**于底板一点，避免功放回流污染 Si5351 与 ADC 参考地。详见待补文档 `docs/13-emc-and-spurious-suppression.md`。

### 3.2 功放模块 `pa-module`

**拓扑**：3× BS170 并联 E 类开关功放。

| 参数 | 数值 |
|------|------|
| 额定输出功率 | **1–2.5 W**（长期安全运行） |
| 峰值短时功率 | **3.5 W**（限时 ≤30 s，需散热片） |
| 低功率档 | **0.02–0.5 W**（PWM 调节升压模块输出电压） |
| 漏极电压 | 12–13.8 V |
| 栅极偏置 | ≈2.1 V 直流（使管子工作在开关状态） |
| 效率 | 60%–73% |
| 总耗散能力 | 约 1.05–2.5 W |

**微功率档实现**：E 类功放输出功率近似正比于 V_dd²，通过 PWM 动态调节升压模块输出电压：

| 升压模块输出 | 漏极电压 | 预估输出功率 |
|-------------|---------|-------------|
| 12 V | 12 V | 2.5 W |
| 5 V | 5 V | ≈0.43 W |
| 3 V | 3 V | ≈0.15 W |
| 2 V | 2 V | ≈0.07 W |
| 1.5 V | 1.5 V | ≈0.04 W |

**偏置电路**

- 分压电阻：10 kΩ + 2.2 kΩ，从 5 V LDO 分压得到约 2.1 V
- 温度补偿：分压电阻下端串联 NTC 热敏电阻（10 kΩ，B=3950）
- 旁路电容：100 nF 陶瓷电容
- 栅极保护：10 V 双向稳压二极管（BZX84-C10）

**散热设计（风险项）**

BS170 标称 R_θJA = 150 °C/W。每管功耗约 0.5 W → ΔT = 75 °C；45 °C 环境下结温 = 120 °C，**余量仅 30 °C**。

| 措施 | 说明 |
|------|------|
| 实测判定 | 2.5 W 连续发射 30 分钟，热电偶实测 TO-92 壳温 **<85 °C** |
| 兜底方案 1 | 若超限，额定功率下调至 **2 W** |
| 兜底方案 2 | 预留 **IRF510 兼容焊盘**（TO-220，Pd=20 W，成本仅多约 1 元），需要 5 W 输出时必须换用 |
| 结构 | 预留散热片安装位与风道（见 `enclosure/`） |

### 3.3 低通滤波模块 `lpf-module`

| 参数 | 数值 |
|------|------|
| 拓扑 | 三阶椭圆低通 |
| 中心频率 | 3.55 MHz |
| 2f₀（7.1 MHz）衰减 | **≥55 dB** |
| 验证 | SDR 接收机实测杂散 |

### 3.4 自动天调模块 `atu-module`

**为什么需要 ATU**：80 m 波段 5 m 短导线天线的输入阻抗呈**高电抗、低辐射电阻**特性，无匹配网络时发射效率极低。

**实测负载特性**

挂树状态：

| 测量点 | 实部 R (Ω) | 虚部 jX (Ω) | 所需串联电感 (µH) |
|--------|-----------|-------------|------------------|
| 1 | 115.1 | -1180 | 33.9 |
| 2 | 134.4 | -1120 | 32.0 |
| 3 | 122.7 | -1010 | 30.0 |
| 4 | 124.3 | -996 | 29.8 |
| 5 | 122.2 | -991 | 29.8 |
| 6 | 122.0 | -990.7 | 29.8 |

→ 所需串联电感约 **30–34 µH**

实验室状态：

| 测量点 | 实部 R (Ω) | 虚部 jX (Ω) | 所需串联电感 (µH) |
|--------|-----------|-------------|------------------|
| 1 | 50.48 | -1110 | 49.8 |
| 2 | 48.92 | -1110 | 49.8 |
| 3 | 68.6 | -1070 | 47.5 |
| 4 | 62.96 | -1040 | 46.2 |
| 5 | 87.75 | -1030 | 35.0 |

→ 所需串联电感约 **35–50 µH**

**匹配网络：L 型，6 只继电器，64 种组合**

电感阵列：

| 位 | 电感值 | 继电器 | 磁芯 | AL 值 | 绕制参数 |
|----|--------|--------|------|-------|---------|
| L1 | **12 µH** | K1 | T37-6 | 3.0 nH/N² | 约 63 圈 |
| L2 | **33 µH** | K2 | T106-6 | 11.6 nH/N² | 约 53 圈 |
| L3 | **47 µH** | K3 | T106-6 | 11.6 nH/N² | 约 64 圈 |

8 种电感组合：0 / 12 / 33 / 45 / 47 / 59 / 80 / 92 µH

电容阵列：

| 位 | 电容值 | 继电器 | 接入条件 |
|----|--------|--------|---------|
| C3 | **22 pF** | K4 | K4 吸合时接入 |
| C4 | **120 pF** | K5 | K5 吸合时接入 |
| C5 | **330 pF** | K6 | K6 吸合时接入 |

8 种电容组合：0 / 22 / 120 / 142 / 330 / 352 / 450 / 472 pF

**覆盖验证**

| 实测场景 | 所需电感 | 可用组合 | 残抗 | 预估 SWR |
|---------|---------|---------|------|---------|
| 挂树（30–34 µH） | 30–34 | **33 µH** | ±3 µH | **<2.5** |
| 实验室（35–50 µH） | 35–50 | **45** 或 **47 µH** | ±4 µH | **<2.0** |
| 实验室（49.8 µH） | 49.8 | **47 µH** | -2.8 µH | **<1.8** |

**电容耐压**：谐振高压可达 **816 Vrms** → 选用 **NP0 1206/1812，耐压 ≥630 V**。

**继电器与驱动**（借鉴 ATU-100）

继电器型号 **HK4100F-DC-12V**：

| 参数 | 数值 |
|------|------|
| 触点形式 | SPDT（1C） |
| 触点容量 | 3 A @ 250 VAC / 30 VDC |
| 线圈电压 | 12 VDC |
| 线圈电阻 | 720 Ω |
| 线圈额定电流 | 16.7 mA（6 只同时吸合约 100 mA） |
| 动作时间 | 6 ms |
| 释放时间 | 4 ms |
| 接触电阻 | 100 mΩ |
| 封装 | DIP，14.5 × 10.5 mm |
| 电气寿命 | 10 万次（额定负载） |
| 机械寿命 | 1000 万次 |

驱动电路 **2N7002 + 1 µF 陶瓷电容**：

```
ESP32-C3 / TCA9535 ──100Ω──► 2N7002 栅极(G)
                              │
                            10kΩ
                              │
                             GND
2N7002 源极(S) ──► GND
2N7002 漏极(D) ──► 继电器线圈 ──► +12V
                    │
                   1µF 陶瓷电容（跨接线圈，限制反电动势）
```

关键设计要点：

- 2N7002 在 3.3 V GPIO 下 R_ds(on) ≈ 1.6–4.5 Ω，16.7 mA 线圈电流下压降仅 0.03–0.08 V，吸合可靠。
- **100 Ω 栅极电阻**抑制振铃；**10 kΩ 下拉电阻**确保关断。
- **1 µF 陶瓷电容**跨接线圈，反峰限制在约 20 V；2N7002 V_dss = 60 V，裕量充足。
- 可**同时保留 1N4148 续流二极管**作为冗余保护，两者并联不冲突。

**无功电流热核算**

调谐后回路无功电流约 **0.408 A rms**，T106-6 绕组需承载 0.4 A rms @3.5 MHz。

| 参数 | 数值 | 说明 |
|------|------|------|
| 无功电流 | 0.408 A rms | 由串联谐振决定 |
| 趋肤深度 | ≈35 µm @3.5 MHz | 0.4 mm 导线有效截面积下降 |
| 推荐线径 | **0.5 mm 漆包线** | 降低 AC 电阻 |
| 热测试 | 模拟 15-j2000 Ω 负载，2.5 W 连续 30 分钟 | 磁环表面温度 **<70 °C** |

**T106-6 SRF**：约 **6.0 MHz**（需实测验证）。

**天线静电泄放**：ATU 输入端增加 **1 kV 高压电阻（100 kΩ）到地**，或射频专用 GDT。

### 3.6 电源模块 `power-module`

| 电压轨 | 方案 | 负载 |
|--------|------|------|
| **5 V 主轨** | MP2315 同步降压 | 继电器驱动、偏置分压 |
| **3.3 V 射频** | MD7673 LDO | Si5351 本振（低噪声） |
| **3.3 V 数字** | 独立 π 型 RC 滤波 | ESP32-C3、LCD、扩展器 |
| **12 V 功放** | 升压模块（**PWM 可调**） | 功放漏极、继电器线圈 |

> **关键**：Si5351 供电与数字电源必须**分轨 + π 型滤波**。原项目 7805 LDO 效率约 68%、发热严重，本方案改用 MP2315 同步降压。

**电池续航（2S 500 mAh）**

| 工作模式 | 功放电流 | 控制电流 | ATU 继电器 | 总电流 | 续航 |
|----------|---------|---------|-----------|--------|------|
| 连续发射 @2.5 W | 0.5 A | 0.2 A | 0.100 A | 0.800 A | ≈38 分钟 |
| 竞赛模式（1/5 占空比，继电器持续吸合） | 0.1 A | 0.2 A | 0.100 A | 0.400 A | ≈75 分钟 |
| 竞赛模式（**静默期释放继电器**） | 0.1 A | 0.2 A | 0 A | 0.300 A | **≈100 分钟** |
| 静默待机（继电器释放） | 0 | 0.2 A | 0 A | 0.200 A | ≈150 分钟 |

> **省电设计**：静默期释放继电器可把竞赛模式续航从 75 分钟提升到约 100 分钟。这要求软件在发射窗口开始前预留继电器吸合时间（6 ms）+ 稳定时间。

**纹波要求**：2.5 W 发射时 12 V 升压轨纹波峰峰值 **<0.5 V**。

### 3.7 天线系统 `antenna`

| 项目 | 要求 |
|------|------|
| 天线长度 | **5 m**（推荐），最小 4 m，最大 8 m |
| 地线 | **至少 5 m**，推荐 3 段 × 2 m 辐射状铺设 |
| 架设方式 | 垂直悬挂，远离树干和金属物体 |
| 部署后操作 | **必须重新调谐**，NVS 记忆仅作起点 |
| 实测典型阻抗 | 挂树：R≈120 Ω，X≈-1050 Ω；实验室：R≈50–88 Ω，X≈-1100 Ω |
| 所需串联电感 | 挂树：约 30–34 µH；实验室：约 35–50 µH |
| 所需并联电容 | 挂树：约 25 pF；实验室：0–450 pF |

### 3.8 互联定义 `interconnect`

**这是硬件区与软件区的第二个契约点**（第一个是 GPIO 分配）。

必须定义：

| 项 | 内容 |
|----|------|
| 射频互联 | 各模块 SMA 座定义（PA-OUT ↔ LPF-IN ↔ ATU-IN ↔ ANT）、阻抗 50 Ω、线缆型号与长度 |
| 电源互联 | 各模块电源针脚定义、电流上限、线径 |
| 控制互联 | 控制信号（PA_EN、CW_KEY、功率 PWM、ADC 检波）的针脚与电平定义 |
| 机械互联 | 模块固定孔位、板间距、SMA 高度匹配 |
| 线束 | 线束图、压降核算、抗拉与固定方式 |

**验证要点**：连接器插拔寿命、SMA 力矩、线束压降。

### 3.9 结构件 `enclosure`

- 3D 打印或通用塑料盒。
- 需考虑：功放散热风道、ATU 继电器机械噪声隔离、电池仓、天线与地线出口。
- 验证：装配干涉检查。

## 4. 硬件版本管理

### 4.1 版本号规则

```
V<主>.<次>
```

| 变更类型 | 版本动作 | 示例 |
|---------|---------|------|
| 板框 / 接口 / 关键器件变更（不兼容） | **主版本 +1** | V1.2 → V2.0 |
| 布局优化、元件替换（兼容） | **次版本 +1** | V1.0 → V1.1 |

被替代的版本移入 `hardware/archive/<模块>/<版本>/`，保留原始发布日期与替代原因。

### 4.2 文件命名

```
<模块名>-<板号>-<版本>.<扩展名>
```

示例：`atu-module-V1.0.kicad_sch`、`pa-module-V1.1-gerber.zip`、`core-board-V1.0-bom.xlsx`

完整规范见 [02-仓库目录规范](02-repository-layout.md) §4.1。

### 4.3 发布产物

每个硬件版本发布时必须包含：

| 产物 | 位置 |
|------|------|
| 原理图源文件 + PDF | `<模块>/schematic/` |
| PCB 源文件 | `<模块>/pcb/` |
| Gerber / 钻孔 / 贴片坐标 | `<模块>/gerber/` |
| BOM（含封装、位号、替代料） | `<模块>/bom/` |
| 装配图 | `<模块>/schematic/` 或 `<模块>/mechanical/` |
| 结构件（STL/STEP） | `hardware/enclosure/` |
| 模块实测报告 | `<模块>/test/` |

| 7 | T106-6 磁环温升 | 磁芯参数漂移、失谐 | 0.5 mm 线径；表面温度 <70 °C 判据 | [stage-2](../validation/stage-2-matching-network/README.md) |
| 8 | 模块连接器引入插损 | 输出功率下降 | 连接器规格筛选；[stage-2](../validation/stage-2-matching-network/README.md) 插入损耗判据 | — |
| 9 | GPIO 数量紧张 | 功能无法全部实现 | TCA9535 扩展器 + LCD `CS` 接地/`RST` 共用 + **CW 键控走 Si5351 使能**（[ADR-0008](adr/ADR-0008-st7567-spi-and-pa-keying.md)） | [05-接口契约](05-hw-sw-interface-contract.md) |
| 10 | 天线部署环境差异大 | 匹配失败 | 部署后必须重新调谐；64 组合覆盖实测负载 | [stage-0](../validation/stage-0-rf-frontend/README.md) |
