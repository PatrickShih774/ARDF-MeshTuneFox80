## 1. 架构总原则

整机采用 **「核心底板 + 可插拔射频模块」** 架构：

```
┌───────────────────────────────────────────────────────────────┐
│                    核心底板 core-board                         │
│                    130 × 95 mm  四层板                         │
│                                                               │
│   ┌────────────┐  ┌────────────┐  ┌────────────┐             │
│   │ mcu-ui-    │  │ power-     │  │ lpf-       │             │
│   │ module     │  │ module     │  │ module     │             │
│   │ (插座)     │  │ (插座)     │  │ (插座)     │             │
│   └────────────┘  └────────────┘  └────────────┘             │
│                                                               │
│   ┌────────────┐  ┌────────────┐                              │
│   │ pa-module  │  │ atu-module │   SMA 互联 + 排针互联         │
│   │ (插座)     │  │ (插座)     │                              │
│   └────────────┘  └────────────┘                              │
└───────────────────────────────────────────────────────────────┘
```

**为什么模块化**

| 收益 | 说明 |
|------|------|
| 独立迭代 | 射频模块可单独改版，不必重投整板 |
| 分级调试 | 按 ATU 专项验证方案逐模块验证（见 [validation/](../validation/README.md)） |
| 成本控制 | 功放管、继电器等易损件可单独更换 |
| 扩展性 | 未来替换为 IRF510 版本（5 W）只需改功放模块 |
| 风险隔离 | 功放击穿不波及主控 |

**代价**：连接器引入插损与可靠性风险、体积增大、BOM 项增多。连接器规格必须在 `hardware/interconnect/` 中定义并做插拔寿命验证。

## 3. 各模块设计要点

### 3.1 核心底板 `core-board`

- **四层板**：信号 / 地 / 电源 / 信号，地平面完整。
- **尺寸**：130 × 95 mm。
- **承载**：各模块插座的机械与电气互联、电池座、天线座、SMA 转接。
- **接地策略**（关键）：射频地与大电流功放地**单点汇集**于底板一点，避免功放回流污染 Si5351 与 ADC 参考地。详见待补文档 `docs/13-emc-and-spurious-suppression.md`。

### 3.2 功放模块 `pa-module`

**拓扑**：3× BS170 并联 E 类开关功放。

🔴 **供电口径（2026-10-11 定案，2026-10-17 设计点定案）**：功放**直接吃 `VCC` 原压**（2S 锂电直供 6.0–8.4 V，标称 7.4 V），**本项目不设升压**；E 类按 **V_CC = 7.4 V（标称）定点**设计（🔴 2026-10-17 用户裁定：8.4 V 定点作废），功率随电量按 `P ∝ V_CC²` 自然下滑。

| 参数 | 数值 |
|------|------|
| 额定输出功率 | **2.5 W @ V_CC = 7.4 V（标称）**；满电 8.4 V → ≈3.2 W（✅ 甲方案：**接受、不降驱动**）；6.0 V → ≈1.64 W |
| 峰值短时功率 | 与额定同（**无升压 ⇒ 不能超压**）；原 3.5 W 指标作废 |
| 低功率档 | **0.02–0.5 W** —— 实现路径见下方 **§3.2.1「功率控制的可行手段」** |
| 漏极电压 | **6.0–8.4 V（= VCC 电池原压）**，**设计点 7.4 V** |
| 栅极偏置 | ≈2.1 V 直流（使管子工作在开关状态） |
| 效率 | 60%–73% |
| 总耗散能力 | 约 1.05–2.5 W |

**E 类设计点（f = 3.55 MHz，ω = 2.23×10⁷ rad/s，V_CC = 7.4 V 标称 / P = 2.5 W）** —— 🔴 2026-10-11 由 8.4 V 改为 **7.4 V 标称**（用户裁定：2S 标称电压即满足 2.5 W）

| 量 | 公式 | 结果 | 说明 |
|---|---|---|---|
| 最佳负载电阻 | `R ≈ 0.5768·V_CC²/P` | **≈ 12.6 Ω** | 原 12 V 设计 ≈33 Ω、按 8.4 V 则为 16.3 Ω ⇒ **匹配/LPF 必须按 12.6 Ω 重做** |
| 开关峰值电压 | `≈ 3.56·V_CC` | **≈ 26.3 V** | 选 **V_ds ≥ 60 V**（BS170 = 60 V，余量 2.3× ✓） |
| 并联电容 | `C1 ≈ 0.1836/(ω·R)` | **≈ 0.65 nF** | 需扣除管子 C_oss（3×BS170 ≈75 pF，占比小） |
| 串联谐振电感 | `L ≈ Q_L·R/ω`（Q_L≈5） | **≈ 2.8 µH** | 另需供电扼流圈 RFC |
| 供电平均电流 | `I ≈ P/(η·V_CC)` | **≈ 0.42 A @7.4 V** | η≈80% |

**功率–电压关系**（E 类输出 ∝ V_CC²；漏极 = 电池原压，本项目无升压）：

| VCC（电池） | 预估输出功率 | 耗散（η≈65%） |
|-------------|-------------|---------------|
| 8.4 V（满电） | **≈ 3.2 W** ⚠️ 超 2.5 W 指标 | ≈1.7 W ✅ 仍在 3×TO-92 的 2.5 W 能力内 |
| **7.4 V（标称）** | **2.5 W** ✅ **设计点** | ≈1.35 W ✅ |
| 6.8 V（低电告警） | ≈ 2.1 W | ≈1.1 W ✅ |
| 6.0 V（放电截止） | ≈ 1.64 W | ≈0.9 W ✅ |

⇒ **功率口径（2026-10-11 定稿）**：**2.5 W 定义在 V_CC = 7.4 V（标称）**；满电 8.4 V 时输出 ≈**3.22 W** —— ✅ **甲方案（用户裁定）：接受该值、不降驱动**（class-E 全程保持理想 ZVS，效率与杂散最优）；固件**只用 `ADC_FWD` 如实上报实测功率**，不做降额。⚠️ 若将来赛事规则限制功率上限，再启用 §3.2.1 的路径①（降 Si5351 驱动，须连带复测谐波）。

#### 3.2.0 🔴 设计点为什么取 **7.4 V（标称）** 而不是 8.4 V（满电）

**决定性理由：2S 电池的容量大部分不在 8.4 V，而在 ≈7.4 V 平台上。**

```
8.4 V ──┐（刚充满，容量占比很小）
        └── 快速跌到 7.6–7.4 V ← 平台期，占 2S 容量的大部分
7.4 V ═══════════════════════════  ← 设计点放这里 = 平时就工作在额定功率
7.2 V ──┘
6.0 V ── 放电截止（功率已降到 ≈1.64 W，无升压的必然结果）
```

| 设计点选择 | 7.4 V（标称）时的输出 | 8.4 V（满电）时的输出 | 6.0 V 时 | 评价 |
|---|---|---|---|---|
| **按 8.4 V 设计** | **≈1.94 W** ❌ 达不到 2.5 W | 2.5 W（但只在刚充满的短时间） | ≈1.28 W | ❌ **只有在满电几分钟内才能达到指标** ⇒ 不可取 |
| **按 7.4 V 设计（选定）** | **2.5 W** ✅ 设计点即标称 | **≈3.22 W** ⚠️ 超指标（耗散 1.73 W，仍在 3×TO-92 的 2.5 W 内 ✓） | ≈1.64 W | ✅ **平时就达标**；满电端偏高需处理 |

**⭐ 一个关键事实（正面）**：按 7.4 V 定点的匹配网络在 8.4 V 下**依然正确** —— 因为 `R_opt = 0.5768·V²/P` 中 P 本身随 V² 走 ⇒ **R_opt 不随电压变，恒为 12.6 Ω** ✓；class-E 的 ZVS 条件由网络与负载决定，**在两档电压下都成立**（只是电流更大、输出更响）✓。**这与"降驱动压功率"不同**：降驱动会破坏 ZVS（效率↓、谐波↑）✗，而"电压升高"不会 ✓。

**因此满电端的处理（✅ 已定：甲方案，2026-10-11）**：
- ✅ **(甲) 接受满电 ≈3.2 W，不做降驱动**（**已采纳**）：class-E 全程保持理想、效率与杂散最好；代价是"刚充满时功率比标称高 29 %"，由 `ADC_FWD` 如实上报 ✓。⚠️ 前提：赛事规则不设更低功率上限。
- (乙) 固件闭环降 Si5351 驱动钉在 2.5 W ±10 %（**未采纳**，仅在将来出现功率上限规则时启用）：功率恒定，但欠驱动 ⇒ ZVS 变差、效率降至 ≈50–60 %、**谐波须按 stage-6 复测**（≥55 dB）✗

> 若你希望 **7.4–8.4 V 全区间都贴近 2.5 W**，还有第三种：**设计点取 ≈7.8 V 中间值**（7.4 V→≈2.25 W、8.4 V→≈2.90 W，误差 ±16 % 两头摊平）—— 但这会把"标称 = 2.5 W"改成"标称 ≈2.25 W"，需重定口径。

##### 3.2.1 `PA_PWR_PWM`（GPIO12）原本怎么调功，现在为什么失效，以及替代手段

**① 它原来的工作原理（历史方案，已作废）** —— 调功**不是**调栅极，而是**调漏极供电电压**：

```
GPIO12 (LEDC PWM, 数百 Hz~kHz)
   └─> RC 低通（PWM → 直流，占空比 ↔ 电压）
        └─> 升压模块的 FB（反馈）节点   ← 改变升压输出电压（1.5 … 13.8 V）
             └─> E 类功放漏极 V_dd
                  └─> 输出功率 P ∝ V_dd²   ← 所以占空比 → 功率 是平方律映射
```
即：**PWM 占空比 = 一个"可编程电压源"的设定值**；E 类只需保持开关状态不变，功率就随 V_dd² 变化 ⇒ 0.02–2.5 W 全范围可调（这也是"微功率档"的实现方式）。

**② 现在为什么失效（2026-10-11）**：本项目**取消了升压** ⇒ 漏极直接吃 `VCC`（电池），**没有任何可被 PWM 改变的电压节点** ✗ ⇒ `PA_PWR_PWM` **失去控制对象**。
> 🔴 **2026-10-11 终态更新**：`docs/05 §7 #7a` **已关闭** —— **GPIO12 已改作示波器打点**（`BOARD_SCOPE_TP`，不接任何被控对象），
> 即"该脚悬空待定"的状态**结束**：它**已经定案为调试测试点**，**不再可能**用 GPIO12 去调功。
> ⇒ 下文的替代手段里，凡写"用 GPIO12 → buck FB"（③）或"`PA_PWR_PWM` 复活"的，
> **都需先重开 `docs/05 §7 #7a` 并重新分配该脚**（本版不做）。

**③ 替代手段（四条，可组合）**

| # | 手段 | 覆盖范围 | 硬件 | 代价 |
|---|---|---|---|---|
| ① | **调 Si5351 输出驱动强度** `CLKx_DRV`（2/4/6/8 mA 四档）| 约 **−12 dB**（2.5 W → ≈0.16 W 理论值，实测非线性）| **零**（本就在 I²C 上）| 欠驱动下 ZVS 变差 ⇒ 效率降到 ≈50–60 %、**谐波可能上升**（须复测）；档位粗、需闭环标定。**用途限定**：仅用于**微功率档**（0.02–0.5 W）；**不再用于满电压制**（甲方案已接受 8.4 V 下的 3.22 W ✓）|
| ② | **栅极偏置 PWM 降额**（PWM+RC 改 2.1 V 偏置）| 连续可调 | 1 个 GPIO/RD 网络 | 让管子脱离开关态 ⇒ **效率崩、发热** ⇒ 只适合小幅微调 |
| ③ | **`VCC → buck → PA 轨` 调压**（用 GPIO12 → buck FB）| **0.02–2.5 W 全范围**（P ∝ V²）| 一颗降压 + 网络 | 多一级硬件；但**同时**解掉 12 V 兼容、效率与谐波最干净、`PA_PWR_PWM` 复活 ✓ |
| ④ | **输出端切换 π/T 衰减器**（用 ATU 的 ~~CA-DV8008 空闲通道 OC7/OC8~~ 切 2 档电阻）| 离散档（如 −6/−12 dB）| 3–6 个电阻 + 继电器/模拟开关 | 离散、有插入损耗；~~**零 GPIO** ✓（吃空闲通道 ✓）~~ → 🔴 **2026-10-11 该前提已失效**：**OC7/OC8 保持空闲、不预接**（用户明确要求"不要动，空着"）⇒ 本手段若要做，**必须另寻通道（或重开 OC7/OC8 的分配）**；适合做"微功率档"的粗档 |
| ✗ | ~~天线端失配/减少输出级~~ | — | — | 🔴 严禁（杂散与器件应力风险）|

**④ 建议组合**：**① + ④** = 零/极低成本即可覆盖"2.5 W → 0.5 W → 0.1 W → 0.02 W"四档（①给连续微调、④给粗档）；若后续要求**全范围干净可调**或要重新引入 12 V 兼容，则改走 **③**（届时需**重开 `docs/05 §7 #7a` 并重新给 GPIO12 一个控制型归属** —— 本版 GPIO12 已定案为示波器打点）。**微功率档的档位定义与实测标定留待 stage-4/stage-8 验证。**

> 🔴 **2026-10-11 本版口径（重要）**：上述①–④**本版一条都不实施**。现行定案是
> **"功放恒定按 7.4 V 标称定点输出、不做降额"**（甲方案，`docs/05 §7 #7b/#7c`；🔴 2026-10-17 用户裁定设计点统一 7.4 V），
> 固件**只用 `ADC_FWD` 如实上报实测功率**。④ 所依赖的"空闲 OC7/OC8"**已明确保持空闲、不预接**。

#### 3.7.1 为什么 +5 V 级不能用 7805 类 LDO（2026-10-11 评估）

| 方案 | 2S 末端 6.0 V | 8.4 V 满电 · 0.35 A | 结论 |
|---|---|---|---|
| **7805（经典三端）** | ❌ **失去调整**：需 Vin ≥ 7.0–7.5 V（压差 2–2.5 V）⇒ 输出塌到约 3.5–4.5 V，**低于继电器吸合门限 3.75 V** ⇒ ATU 直接失效 | — | **不可用** |
| 5 V 低压差 LDO（dropout ≤0.5 V） | ✅ 可维持（6.0 V 仍够） | ❌ 耗散 `(8.4−5)×0.35 = **1.19 W**`（需 DPAK + 铺铜/散热片；同工况 MP2315 仅 ≈0.24 W） | 电气可行 · **热与续航不可行** |
| **MP2315 降压（现行）** | ✅ | ✅ ≈0.24 W | ✅ 维持 |

- **压差是决定性理由**：2S 放到 6.0 V 时 7805 无法维持 5 V，而本项目 5 V 轨要驱动 **6 只 5 V 继电器线圈**（吸合门限 3.75 V）⇒ 会直接失效，不是"效率差一点"的问题。
- **热与续航**：LDO 效率 = `5/Vin` ⇒ 8.4 V 时仅 **59 %**；多出的 1 W 级损耗落在密闭小机箱里、且紧邻射频区 ✗（续航按 2S 500 mAh ≈3.7 Wh 估，影响可达 −20 % 量级）。
- **能简化的正确做法**：+5 V 级改用**成品 2S→5 V 降压模块**（宽输入 6–24 V / 1–2 A，单器件）⇒ 省掉 MP2315 的外围（电感、输入输出电容、布局与 EMI 调试），风险更低；**+3V3 仍保留 LDO**（MD7673，低噪声、压差小、负载仅 50–200 mA）✓
- 🔴 若坚持用 LDO，唯一自洽的代价是**把放电截止从 6.0 V 抬到 ≥7.5 V**（牺牲 2S 约 30–40 % 可用容量）—— 不建议。

#### 3.7.2 vbat 分压重算（覆盖 2S + 12 V，具体阻值）

现行拓扑（[docs/05 §2.7](05-hw-sw-interface-contract.md)）：`VBAT ──[R1]──┬──[R2]── GND`，节点经 `[R3 1k]` 进 ADC。
**比值 = `R2/(R1+R2)`** ⇒ 现行 `9.1/(22+9.1) = 0.2926`（满量程 **11.3 V**）⇒ 12 V 时 **3.51 V 饱和** ✗。

**推荐改 `R1: 22k → 30k`（R2 / R3 不动）**：

| 量 | 现行（22k/9.1k/1k） | **推荐（30k/9.1k/1k）** |
|---|---|---|
| 比值 `R2/(R1+R2)` | 0.2926 | **0.2327** |
| 满量程 | 11.3 V | **14.18 V** ✅ 覆盖 12 V（余量 2.18 V） |
| 源阻抗 `R3 + (R1∥R2)` | 7.44 kΩ | **7.98 kΩ** ✅ < 10 kΩ（ESP32-C3 ADC 要求） |
| 6.0 V（截止） | 1.76 V | 1.40 V ✅ |
| 7.4 V（标称） | 2.17 V | 1.72 V ✅ |
| 8.4 V（满电） | 2.46 V | 1.96 V ✅ |
| **12.0 V（外接）** | **3.51 V ❌ 饱和** | **2.79 V ✅** |
| 静态电流（8.4 V） | 270 µA | **≈ 215 µA** ✅ |
| 结论 | 仅够 2S | **2S + 12 V 兼容，只需换一颗电阻** |

> 若采用"增设 12 V 输入检测 + 两套标定"路线（docs/05 §7 #7d 方案②），则保留现行阻值 + 增加一路检测 —— 但**无空闲 GPIO**，检测只能复用同一 ADC 读数（软件判"是否 >11.3 V 饱和区"），可靠性低于直接改阻值。

#### 3.7.4 ⚠️ 若给功放加"降压级"，先看清它只能"向下调"（决定选型）

降压（buck）**只能把电压调低**，不能抬高 ⇒ 该级在不同输入下的行为完全不同：

| 输入 | 降压级设定 8.4 V 时的实际输出 | 对功放的意义 |
|---|---|---|
| **12 V 外接** | ✅ 稳定 8.4 V（余量 3.6 V） | **正是它存在的理由**：把 12 V 降到 E 类定点，避免 5.1 W / 耗散翻倍 / 峰值 42.7 V ✗ |
| 8.4 V（满电） | ≈ 8.4 V（占空比 ≈100 %，近似直通） | 与"直供"等价 |
| 7.4 V（标称）/ 6.0 V（截止） | **只能给到输入电压本身**（6.0–7.4 V）⇒ 轨 = 电池 | ❗ **它无法把 PA 轨稳在 8.4 V** ⇒ 功率仍随电量按 `P ∝ V²` 下滑（7.4 V→1.94 W、6.0 V→1.28 W）—— 这是"无升压"的必然结果，不是降压级的缺陷 |

⇒ **推论**：加这一级能解决 **12 V 兼容** 与**调功**（可低到 ~3 V 供微功率档，~~顺带复活 `PA_PWR_PWM`~~ → 🔴 **2026-10-11：本版不做** —— GPIO12 已定案为**示波器打点**，要复活须先重开 `docs/05 §7 #7a`），

| **MP2315 模块** | 4.5–24 V | 5 V / 3 A | 与现用 U9 同芯片，**功能口径不变**（只是把外围交给模块） | 同样优选固定输出版 |
| **XL4015 模块** | 5–32 V（UVLO≈5.5 V） | 5 V / 5 A | 余量大、便宜 | 6.0 V 输入时接近其下限，需实测启动；体积较大 |
| **LM2596 模块** | 4.5–35 V | 5 V / 3 A | 极常见、最便宜 | 效率仅 ≈75% ⇒ 8.4 V/0.4 A 时多耗 ≈0.3 W；需散热片；**不推荐用于本机** |

**选型要求（无论选哪款）**：① 输入下限 ≤ **6.0 V** 且能在 6.0 V 下正常启动与带载；② 输出 **5 V ±3 %**（固定版）；③ 持续 **≥1.5 A**（继电器 240 mA + 偏置 + 背光 + 余量）；④ 输出纹波 <50 mVpp 或后级加 π 滤波；⑤ 优选**固定输出**（免电位器误调）。
> 说明：该 5 V 轨只驱动**继电器线圈 / 栅极偏置 / 背光**（对噪声不敏感），后级 3.3 V 由 LDO 再稳压 ⇒ 模块的开关噪声不直接进本振，风险可控。
> ⚠️ **本项为"可选简化"，不阻塞设计**：沿用现有 MP2315 分立方案（输入 4.5–24 V，已满足 2S 与 12 V）同样成立 ✓ —— 待用户最终选择后同步 BOM。

#### 3.7.6 ❌ ~~12 V 下发射 2.5 W 的落地口径~~ → **作废（2026-10-11 晚：用户取消 12 V 兼容）**

> ❌ **作废**：输入只支持 2S 6.0–8.4 V ⇒ 本节关于"12 V 输入档识别 / 12 V 下降驱动 / 双点标定"的内容**全部不需要** ✗。
> **仍有效的部分**（保留执行）：满电 **8.4 V** 时输出 ≈3.2 W > 2.5 W 指标 ⇒ 固件按 `ADC_FWD` 闭环降 Si5351 驱动把功率压回 **2.5 W ±10 %**；建议给 3×BS170 加散热片/铺铜；单点标定（7.4 V 标称）即可。

**用户裁定**：输入级"兼容 12 V"= **12 V 下也要能发射 2.5 W**；**不增加降压级** ⇒ 由固件实现。

**固件职责（新增契约，登记于 docs/05 §2.5/§7 #7c）**：

| 环节 | 做法 |
|---|---|
| 电压感知 | 用 `ADC_VBAT`（GPIO3，分压 30k/9.1k/1k）读数判断当前输入档：**6.0–9.0 V = 2S 电池**；**>10.5 V = 12 V 外接** |
| 功率钉位 | 12 V 档时**降低 Si5351 输出驱动强度**（`CLKx_DRV`：2/4/6/8 mA，四档约 12 dB 范围）把输出压回 **2.5 W**；8 mA→≈2 mA 一档大致对应 −6…−9 dB，视实测标定 |
| 闭环微调 | 用已有的 `ADC_FWD` 前向功率读数做**闭环**：目标 2.5 W ±10 %，逐档微调驱动强度（不得开环硬编码）|
| 上报诚实 | 界面/日志显示**实测功率**（`ADC_FWD` 换算）与当前输入档，不得用设定值冒充 |
| 保护 | 若 12 V 档下实测 >3.2 W 或壳温异常，**先降驱动再停发**；`SWR>3.0` 停发的既有约定不变 |

**硬件侧配套（无新增器件）**：
- 🔴 **建议给 3×BS170 加 TO-92 散热片 / 加大铺铜** —— 欠驱动下 class-E 效率降到约 50–60 %，2.5 W 输出时耗散仍有 ≈1.0–1.3 W，留余量 ✓
- **峰值 `V_ds ≈ 42.7 V` 在 BS170 60 V 之内** ✓（此项无需处理，之前的"过压"表述已纠正）
- **功率/SWR 标定必须双点标定**：8.4 V（2S 满电）与 12 V 各做一次，固件按输入档选表 ✓

**⚠️ 必须复测的代价（stage-6）**：欠驱动使 class-E 的 ZVS 条件变差 ⇒ **谐波/杂散可能上升**，须按既有判据（2 次谐波 ≥55 dB、其余杂散无异常尖峰）复测；若实测不达标，则回退到**方案①（VCC → 降压 → PA 轨 8.4 V）** —— 该方案仍保留在 §7 #7c 候选里 ✓

> **关键**：Si5351 供电与数字电源必须**分轨 + π 型滤波**。原项目 7805 LDO 效率约 68%、发热严重，本方案改用 MP2315 同步降压。

**电池续航（2S 500 mAh）**

| 工作模式 | 功放电流 | 控制电流 | ATU 继电器 | 总电流 | 续航 |
|----------|---------|---------|-----------|--------|------|
| 连续发射 @2.5 W | 0.5 A | 0.2 A | 0.100 A | 0.800 A | ≈38 分钟 |
| 竞赛模式（1/5 占空比，继电器持续吸合） | 0.1 A | 0.2 A | 0.100 A | 0.400 A | ≈75 分钟 |
| 竞赛模式（**静默期释放继电器**） | 0.1 A | 0.2 A | 0 A | 0.300 A | **≈100 分钟** |
| 静默待机（继电器释放） | 0 | 0.2 A | 0 A | 0.200 A | ≈150 分钟 |

> **省电设计**：静默期释放继电器可把竞赛模式续航从 75 分钟提升到约 100 分钟。这要求软件在发射窗口开始前预留继电器吸合时间（6 ms）+ 稳定时间。

**纹波要求**：功放轨 = `VCC` 电池直供（**无升压 ⇒ 无开关纹波源**）；需实测的是 **5 V 主轨**（继电器线圈 240 mA 脉冲负载）与 **3.3 V 数字轨**的 DC-DC 纹波（目标 **<50 mVpp**），并确认继电器吸合瞬间的跌落不干扰本振与 ADC 参考。

### 3.7 天线系统 `antenna`

| 项目 | 要求 |
|------|------|
| 天线长度 | **5 m**（推荐），最小 4 m，最大 8 m |
| 地线 | **至少 5 m**，推荐 3 段 × 2 m 辐射状铺设 |
| 架设方式 | 垂直悬挂，远离树干和金属物体 |
| 部署后操作 | **必须重新调谐**，NVS 记忆仅作起点 |
| 实测典型阻抗 | 挂树：R≈120 Ω，X≈-1050 Ω；实验室：R≈50–88 Ω，X≈-1100 Ω |
| 所需串联电感 | 挂树：约 30–34 µH；实验室：约 35–50 µH |
| 所需并联电容 | 挂树：约 25 pF；实验室：0–450 pF |

### 3.8 互联定义 `interconnect`

**这是硬件区与软件区的第二个契约点**（第一个是 GPIO 分配）。

必须定义：

| 项 | 内容 |
|----|------|
| 射频互联 | 各模块 SMA 座定义（PA-OUT ↔ LPF-IN ↔ ATU-IN ↔ ANT）、阻抗 50 Ω、线缆型号与长度 |
| 电源互联 | 各模块电源针脚定义、电流上限、线径 |
| 控制互联 | 控制信号的针脚与电平定义。🔴 **实际只有 ADC 检波（`FWD_DET`/`REV_DET`）与电源** —— `PA_EN`/`CW_KEY`/功率 PWM 三者**不存在**（键控 = Si5351 输出使能，见 [`docs/05` §4.2](05-hw-sw-interface-contract.md)） |
| 机械互联 | 模块固定孔位、板间距、SMA 高度匹配 |
| 线束 | 线束图、压降核算、抗拉与固定方式 |

**验证要点**：连接器插拔寿命、SMA 力矩、线束压降。

### 3.9 结构件 `enclosure`

- 3D 打印或通用塑料盒。
- 需考虑：功放散热风道、ATU 继电器机械噪声隔离、电池仓、天线与地线出口。
- 验证：装配干涉检查。

## 4. 硬件版本管理

### 4.1 版本号规则

```
V<主>.<次>
```

| 变更类型 | 版本动作 | 示例 |
|---------|---------|------|
| 板框 / 接口 / 关键器件变更（不兼容） | **主版本 +1** | V1.2 → V2.0 |
| 布局优化、元件替换（兼容） | **次版本 +1** | V1.0 → V1.1 |

被替代的版本移入 `hardware/archive/<模块>/<版本>/`，保留原始发布日期与替代原因。

### 4.2 文件命名

```
<模块名>-<板号>-<版本>.<扩展名>
```

示例：`atu-module-V1.0.epro`（立创EDA 专业版工程）、`pa-module-V1.1-gerber.zip`、`core-board-V1.0-bom.xlsx`

完整规范见 [02-仓库目录规范](02-repository-layout.md) §4.1。

### 4.3 发布产物

每个硬件版本发布时必须包含：

| 产物 | 位置 |
|------|------|
| 原理图源文件 + PDF | `<模块>/schematic/` |
| PCB 源文件 | `<模块>/pcb/` |
| Gerber / 钻孔 / 贴片坐标 | `<模块>/gerber/` |
| BOM（含封装、位号、替代料） | `<模块>/bom/` |
| 装配图 | `<模块>/schematic/` 或 `<模块>/mechanical/` |
| 结构件（STL/STEP） | `hardware/enclosure/` |
| 模块实测报告 | `<模块>/test/` |
