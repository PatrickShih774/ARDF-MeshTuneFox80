| # | 硬约束 | 本版现状 | 下版要求 | 一句话原因 |

## 1. 故障回放（硬件视角，只写与 PCB 有关的部分）

### 1.1 现象与排除过程

| 项 | 内容 |
|---|---|
| 现象 | ST7567 12864 屏：**背光亮、屏幕完全无任何显示**（连面板级「全亮」命令也不出） |
| 同一模块在参考项目（STM32） | **能正常显示** ⇒ 模块本体是好的 |
| 已排除（固件/接线侧） | 初始化命令序列、帧缓冲 CRC、GPIO 翻转（示波器 + 回读）、硬件 SPI2 / 软件位敲、64 档对比度扫描 —— 全部有证据 |
| 根因 | **面板缺少一次真正的硬件 RST 脉冲**：本板 `RST` 与板复位共用，没有 MCU 可驱动的复位沿 ⇒ 面板内部上电复位/复位释放时序未完成 ⇒ 命令进不去 ⇒ 全黑 |

### 1.2 决定性对照（一句话）

> 同一块屏、同一套接线，**只把 `RST` 从"板复位网络"改由 MCU 主动发三段脉冲（高 5 ms → 低 5 ms → 高 5 ms）**
> ⇒ **点亮**；而在改接之前，用「板复位 + 仅软件复位 `0xE2`」的路径**复位 20 次、屏 0/20 亮**。

### 1.3 与本仓网表的直接对应（这就是要改的两行）

| 网表行 | 网络 | 连接 | 备注（原文） |
|---|---|---|---|
| `hardware/schematic/netlist.csv:49` · `netlist.md:96` | `GND` | `U5.CS` → `GND.-` | 🔴 CS 接 GND: ST7567 是 SPI2 上唯一从机 → 省 1 个 GPIO |
| `hardware/schematic/netlist.csv:50` · `netlist.md:97` | `LCD_RST` | `U5.RST` → `RESET_BOARD.-` | 🔴 RST 与板复位共用: 上电复位即可 → 省 1 脚与 RC 电路 |

> ⚠️ 这两行是**同一次"省脚"决策**的两半：省掉了 `CS` 和 `RST` 两根 MCU 控制线。
> 本次故障证明：**"上电复位即可"这个假设在 ESP32 启动速度下不成立**；
> 而 `CS` 硬接 GND 虽然电气上能工作，但把「片选」变成了不可观测项。

### 1.4 证据边界（诚实声明）

- 本仓**没有原理图/PCB 源文件**（`hardware/*/schematic/` 只有派生网表；2026-10-17 已整套删除 KiCad 骨架）
  ⇒ 本文引用的网表是**脚本派生物**（`scripts/build-netlist.py` / `build-lceda-import-pack.py`），
  **改这三条必须同时改生成器**，否则三份网表会与改版脱节。
- 模组 datasheet 不在本仓（且公开仓不允许放 PDF，见 `docs/08`）⇒ `RST` 最小脉宽 / 上拉要求**待模组资料确认**（§4）。

## 2. 下版 PCB 必须遵守的三条（逐条展开）

### 2.1 第一条：模块 `CS` 走 GPIO，不要硬接 GND

| 项 | 内容 |
|---|---|
| **本版现状** | `U5.CS` 直连 GND（`netlist.csv:49`）；三份网表 / BOM / 装配清单 **四处一致**地写「直连 GND」，没有跳线/0Ω（详见私有固件仓 2026-10-18 的 CS 接地审计报告，本仓不转述）。 |
| **问题** | ① 片选**不可观测**：屏不亮时无法用一根 GPIO 区分「没选中」与「数据没到」；② 片选**不可控制**：无法做「只发命令不写数据」等面板级诊断；③ SPI2 若增加第二个从机，共用片选直接冲突。 |
| **下版要求** | `U5.CS` 先接到一个**测试点/可选 0Ω 到 GND**，正常走 **MCU GPIO**：<br>· 选**非 strapping、非 ADC** 的脚（GPIO 预算见 `docs/17-gpio-allocation-audit.md`）；<br>· 软件定义：**空闲高 = 不选中，低有效 = 选中**（ST7567 `/CS` 低有效）；<br>· BSP 引脚表登记 owner（固件侧已有"同脚不得两个有效主人"断言）。 |
| **验收标准** | 网表出现独立 `LCD_CS` 网络；BOM/装配清单各有一条；上电默认高；`docs/05 §2.2` 与 `ADR-0008 §3.1` 同步更新。 |
| **前置条件** | 🔴 **GPIO 预算已满**（固件侧当前 14/14 已用，`docs/17`）⇒ 本条必须先解决"从哪腾一根脚"，**不能直接抢脚**。 |

### 2.2 第二条：每个 GND 连接点加测试点

| 项 | 内容 |
|---|---|
| **本版现状** | 板上有 `TP1–TP8` 测试点（`bom-mcu-ui-module.csv:25`），建议信号为 3.3V / 5V / 12V / ADC_FWD / ADC_REV / **GND** / I2C_SDA / I2C_SCL；但 **LCD 子系统的 `CS` 脚、`RST` 脚、`U5.VSS`、排针 GND 都没有独立测试点/丝印**。 |
| **问题** | 「CS 接 GND 为什么不亮」这类问题的第一判据是**通断**（CS 脚 ↔ GND 是否 ≈0 Ω）。没有测试点就只能用探针顶排针/金手指/焊盘，接触电阻与误触会让结论反复（本次审计文档之所以要给 M-1…M-5 一整套万用表步骤，就是因为缺少可探针节点）。 |
| **下版要求** | 至少给下列节点留**可探针焊盘或测试点**（丝印建议 `TP_GND_LCD` / `TP_CS_LCD` / `TP_RST_LCD`）：<br>· 屏排针的 **GND 针**（模组参考地）<br>· `U5.VSS` 附近<br>· `U5.CS`（即使按第一条走 GPIO，也留测试点）<br>· `U5.RST`<br>· 背光低边 MOS 源极 `Q5.S` / `R_BL2.2` 地端<br>· 每个"可拆模块"的 GND 连接点（J1–J6 / J17–J22 排针的 GND 针） |
| **验收标准** | 装配清单出现「测试点清单」条目；投板文件有 TP 位号（或明确的裸焊盘）；BOM 有 TP 行；丝印图标注。 |

### 2.3 第三条：`RST` 必须可由 MCU 驱动

| 项 | 内容 |
|---|---|
| **本版现状** | `U5.RST` 与板复位共用（`netlist.csv:50` → `RESET_BOARD`；`pre-fab-checklist.md` **D-10** 明文「ST7567 `RST` 与板复位共用」）。**没有任何 MCU 可控的复位脉冲**。 |
| **问题** | ST7567 的 `RST` 是低有效**硬件**复位输入；面板要进入确定的初始状态，需要一次**从高到低的复位脉冲**并在释放后留出内部初始化时间。**软件复位 `0xE2` 的前提是"芯片已经在能收 SPI 的状态"** —— 复位没完成时它同样进不去。本次故障就是这条：背光亮、全黑，`0xE2` 发了、屏不动。 |
| **下版要求** | `U5.RST` 走**独立网络**到 MCU GPIO（不再与 `RESET_BOARD` 共用）；<br>· 固件初始化序列在发任何面板命令**之前**发一次复位（高→低→高；每段 ≥5 ms，具体按 datasheet）；<br>· 上拉/串联 RC 按模组 datasheet 与模组厂推荐值实现（本仓无 datasheet，§4）；<br>· 网表/装配清单把 D-10 从「与板复位共用」改为「独立 MCU 复位」。 |
| **验收标准** | 网表独立 `LCD_RST` 网络；装配清单 D-10 改写；`docs/05 §2.2` 接口契约同步；真机复测：冷启动 20 次，屏幕 20/20 正常。 |
| **反例警告** | ⚠️ **"模组自带 RC 上电复位"不能替代 MCU 可控复位**：本次故障已经证明「上电复位即可」在 ESP32 启动速度下不成立。 |

## 3. 不列入三条的相关项（避免误读）

| 项 | 为什么不在三条里 |
|---|---|
| **Si5351 无输出** | 根因是**固件寄存器写入**（MSNA 分频块 / CLK 控制寄存器 / PLL 复位），不是 PCB 问题；本仓只需保证 I²C 上拉与 CLK0 → 244 走线（现状无问题）。**可选建议**：下版给 `CLK0` 留一个测试点，便于示波器验证（建议，不强制）。 |
| **PSB（串/并口选择）** | 本版网表未单独引出，依赖模组侧决定；本次不是变量。**换模组时必须确认 PSB 接法**（串行 = GND），建议写入模组采购/验收条目。 |
| **背光驱动链** | 本次完全正常（背光亮）；`R_BL`/`Q5`/`R_BL2` 设计无需改。 |
| **`V0` 偏置/对比度网络** | 网表标「未冻结」；本次故障不是它（64 档扫描无变化），但它仍是**未冻结项**，下版应随模组规格一起冻结。 |
