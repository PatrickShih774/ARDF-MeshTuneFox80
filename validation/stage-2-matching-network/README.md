# stage-2-matching-network —— L 型匹配网络全组合验证

- 时间窗：第 4–6 天
- 状态：未开始

## 1. 验证目标

遍历 6 继电器 L 型匹配网络的全部 **64 种组合**，确认其能覆盖实测负载集，
并在典型与极限阻抗下达到规定的 SWR 指标。

## 2. 被测对象

- L 型可切换匹配网络：L1=12µH(T37-6)、L2=33µH(T106-6)、L3=47µH(T106-6)，
  C=22/120/330pF（NP0，≥630V），6 只 HK4100F-DC-12V 切换
- 负载模拟：50Ω / 100Ω / 150Ω / 10Ω / 20Ω 假负载，以及 LC 模拟负载
  （挂树 120-j1050Ω、实验室 50-j1110Ω、88-j1030Ω）

## 3. 仪器与工装

- NanoVNA-H4（校准至网络输出端面）
- 大功率假负载与可调 LC 负载箱（耐压满足谐振高压测试）
- 继电器驱动板 + 手动/上位机组合切换工具（组合编号 0–63 映射表）
- 高压探头与示波器（电容谐振高压测试）

## 4. 步骤

1. 校正 6 位组合编号到开关状态的映射表，确认 64 种组合均可单独寻址。
2. 逐个组合在 50Ω 负载下测 SWR，记录全部 64 个结果。
3. 分别在 100Ω / 150Ω 负载下遍历全组合，统计 SWR<2.0 的组合数。
4. 分别在 10Ω / 20Ω 负载下遍历全组合，统计 SWR<2.0 的组合数。
5. 用 LC 负载箱模拟挂树 120-j1050Ω，重点测 33µH 档，记录最优 SWR。
6. 模拟实验室 50-j1110Ω，重点测 47µH 档；再模拟 88-j1030Ω，测 45µH 档。
7. 在 R 从 115Ω 扫到 135Ω（保持 X 不变）的过程中记录 SWR 曲线。
8. 对参与谐振的组合做电容两端高压测试，记录峰值电压与有无击穿/飞弧。

## 5. 判据

| 指标 | 判据 | 实测 | 结论 |
| --- | --- | --- | --- |
| 组合遍历 | **64 种组合全部可寻址并实测** | | |
| 50Ω 负载 | ≥**8** 种组合 SWR<1.2 | | |
| 100Ω / 150Ω 负载 | 各 ≥**3** 种组合 SWR<2.0 | | |
| 10Ω / 20Ω 负载 | 各 ≥**3** 种组合 SWR<2.0 | | |
| 挂树 120-j1050Ω | 33µH 档 SWR<**2.5** | | |
| 实验室 50-j1110Ω | 47µH 档 SWR<**1.8** | | |
| 88-j1030Ω | 45µH 档 SWR<**2.0** | | |
| R 扫动 115–135Ω | 全程 SWR<**2.5** | | |
| 电容谐振高压 | 谐振峰值电压下无击穿、无飞弧，余量满足设计 | | |

## 6. 数据与报告

- 64 组 SWR 全表以 `.csv` 存 `raw/`，报告 `report-YYYYMMDD.md` 中给出汇总统计与最优组合清单。
- 组合编号映射表随报告一并入库（文本表格，体积极小）。
