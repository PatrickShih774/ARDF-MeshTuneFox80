# stage-4-opamp —— 检波后级方案对照

- 时间窗：第 10–11 天
- 状态：未开始

## 1. 验证目标

对照两种检波后级方案，判断是否必须引入运算放大器：

- 方案 A：**检波输出直接进 ADC**
- 方案 B：**检波 + LM358 缓冲/放大后进 ADC**

若方案 A 达标，则**优先采用方案 A**（省器件、省失调、省功耗、省板面）。

## 2. 被测对象

- 检波输出阻抗与 ADC 采样网络的匹配情况
- LM358 缓冲电路（同相跟随 + 必要滤波）
- ESP32-C3 ADC 通道（GPIO0–4 中的对应引脚）

## 3. 仪器与工装

- 信号源 / Si5351 激励板 + 2W 假负载与可调失配负载
- 六位半万用表（比对检波直流与 ADC 读数）
- 示波器（观察纹波、建立时间、加载效应）
- 固件侧 ADC 采样与打印工具（仅用于调试，非交付代码）

## 4. 步骤

1. 搭出方案 A：检波输出经 RC 滤波直接接 ADC 输入，记录 RC 取值。
2. 在 2W 与 SWR=1.0/1.5/2.0 条件下，比对万用表读数与 ADC 读数的一致性。
3. 记录方案 A 在无发射（暗态）时的 ADC 底噪与漂移。
4. 观察 ADC 采样瞬间对检波节点的影响（加载效应、纹波）。
5. 搭出方案 B：加入 LM358 跟随器，重复步骤 2–4。
6. 记录方案 B 的静态失调电压、温漂与额外功耗。
7. 对两方案在同一组测试点上做精度、重复性、成本、板面占用与功耗的汇总比较。
8. 给出选型结论：方案 A 达标即采用方案 A。

## 5. 判据

| 指标 | 判据 | 实测 | 结论 |
| --- | --- | --- | --- |
| 方案 A 精度 | SWR 读数误差与 stage-3 判据一致（**<0.2**） | | |
| 方案 A 重复性 | 标准差 **<0.15** | | |
| 方案 A 加载效应 | ADC 采样不导致检波节点明显跌落 | | |
| 方案 A 暗态底噪 | 无发射时读数稳定，不误触发 SWR 判决 | | |
| 方案 B 精度/重复性 | 不劣于方案 A | | |
| 方案 B 失调与温漂 | 记录实测值 | | |
| 选型结论 | **方案 A 达标即优先采用方案 A** | | |

## 6. 数据与报告

- 两方案对照数据以 `.csv` 存 `raw/`；示波器截图同样放 `raw/`。
- 实测报告：`report-YYYYMMDD.md`，结论段必须明确写出最终选型与理由。
