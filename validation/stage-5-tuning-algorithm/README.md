# stage-5-tuning-algorithm —— ATU 调谐算法验证

- 时间窗：第 12–14 天
- 状态：未开始

## 1. 验证目标

验证 ATU 调谐算法（借鉴 N7DDC ATU-100 的**粗调 + 细调 + 全遍历兜底**策略）的
**速度**与**成功率**，并统计 NVS 记忆命中率以评估静默期省电收益。

## 2. 被测对象

- 调谐算法实现（闭源商业组件，运行于独立固件分区，经 IPC 调用）
- 6 继电器 L 型匹配网络 + 定向耦合器/检波前端（即 stage-2/stage-3 的硬件）
- NVS 中的调谐结果缓存表

## 3. 仪器与工装

- 完整 ATU 硬件（匹配网络 + 耦合器 + ADC）
- 可编程 LC 负载箱，覆盖挂树/实验室/边界阻抗
- 秒表或固件侧时间戳日志（毫秒级）
- 上位机调谐监控工具（读取 `ATU_STATUS`）

## 4. 步骤

1. 在 50Ω 基准下执行一次冷启动调谐，记录从 `ATU_TUNE_START` 到收敛的总耗时。
2. 更换为 5 组不同负载，各执行冷启动调谐，记录耗时与最终 SWR。
3. 清空 NVS，重复 30 次冷启动调谐，统计成功率（最终 SWR 达标比例）。
4. 在 NVS 已缓存的前提下，同一负载重复调谐，记录微调耗时。
5. 统计 NVS 命中率：命中即微调收敛的次数 / 总调谐次数。
6. 人为制造不可匹配负载（如极端失配），确认算法能正确报失败并回到安全状态。
7. 记录每次调谐的继电器动作次数，评估机械寿命消耗。

## 5. 判据

| 指标 | 判据 | 实测 | 结论 |
| --- | --- | --- | --- |
| 首次（冷启动）调谐时间 | **<5 秒** | | |
| NVS 微调时间 | **<0.5 秒** | | |
| 调谐成功率 | **>95%** | | |
| NVS 命中率 | 统计并记录（用于评估续航收益） | | |
| 不可匹配负载处理 | 正确报失败、进入安全状态、无误发射 | | |
| 继电器动作次数 | 记录每次调谐的动作次数 | | |
| 收敛后 SWR | 符合 stage-2 对应负载的判据 | | |

## 6. 数据与报告

- 每次调谐的耗时、负载、组合编号、SWR、动作次数以 `.csv` 存 `raw/`。
- 实测报告：`report-YYYYMMDD.md`，须给出成功率与 NVS 命中率的统计口径与样本量。
