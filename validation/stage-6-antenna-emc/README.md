# stage-6-antenna-emc —— 实架天线与电磁兼容

- 时间窗：第 15–18 天
- 状态：未开始

## 1. 验证目标

在**真实架设**条件下验证整机发射链路：调谐是否达标、谐波杂散是否合规、
以及 12V 升压轨在动态负载下的纹波是否可控。

## 2. 被测对象

- 实架 5m 导线天线 + 5m 地线（含树挂与地面两种场景）
- 整机发射链路（Si5351 激励 + 功放 + ATU + 天线）
- 12V 升压电源轨（动态负载条件）

## 3. 仪器与工装

- SDR 接收机（含合适衰减器与带通/低通滤波，防止过载）
- 示波器（配高压/差分探头测电源纹波，注意带宽限制与地线弹簧）
- 功率计、假负载、卷尺、架设工装
- 频谱分析仪（若可得，用于交叉验证杂散）

## 4. 步骤

1. 按 plan 中的实架方式架设 5m 导线 + 5m 地线，记录架设参数。
2. 以 2W 发射，执行 ATU 调谐，记录稳定后的 SWR。
3. 在 3.50 / 3.55 / 3.60MHz 三点重复调谐与 SWR 记录。
4. 用 SDR 在 1–30MHz 范围扫描发射频谱，记录基波与各次谐波电平。
5. 计算 2 次谐波（7.1MHz）相对基波的衰减量。
6. 在 12V 升压轨上，用示波器在 CW 键控切换瞬间（动态负载跳变）测纹波峰峰值。
7. 分别在静默、连续发射、断续键控三种状态下各测一次纹波。
8. 记录整机温升与供电电流，作为 EMC 与热设计的输入。

## 5. 判据

| 指标 | 判据 | 实测 | 结论 |
| --- | --- | --- | --- |
| 实架调谐 SWR（2W） | **<2.0** | | |
| 三点频率 SWR | 3.50/3.55/3.60MHz 均达标 | | |
| 2 次谐波 7.1MHz 衰减 | **≥55dB** | | |
| 其他谐波/杂散 | 记录实测电平，不得出现异常尖峰 | | |
| 12V 升压轨纹波（动态负载） | 峰峰值 **<0.5V** | | |
| 整机温升与电流 | 记录实测值 | | |
