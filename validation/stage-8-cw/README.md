# stage-8-cw —— CW 键控与发射时序

- 时间窗：第 21–22 天
- 状态：未开始

> **软件侧验证**：验证对象是固件键控与发射控制逻辑。
> 对应固件组件：**`rf_keyer`**（CW 码速生成、软起软降、键控时序），
> 依赖 `rf_pa`（功放调压）与 `atu_tuner`（SWR 保护）。

## 1. 验证目标

验证自动发报的**码速准确性**、**识别码正确性**、**软起软降波形**、
**长周期定时精度**、**功率可调范围**以及 **SWR 保护的强制静默**行为。

## 2. 被测对象

- `rf_keyer` 组件：CW 波形生成、点划时长、码速、1KHz 长音插入、软起软降包络
- `rf_pa` 功率控制：0.02–2.5W 可调
- ATU/SWR 保护逻辑：SWR>3.0 时禁止发射
  （🔴 2026-09-27 用户定案：**全仓唯一一条** SWR 门限 = 3.0，源头固件
  `RF_SWR_LIMIT_DEFAULT = 3.0f`。⚠️ **调谐探测期用的是同一条门限** ——
  早期"探测期放宽到 10.0"的做法已作废，故本阶段还须覆盖第 8 步）

## 3. 仪器与工装

- 示波器（测包络上升/下降时间、点划时长）或录音 + 音频分析工具
- 通信接收机或 SDR（听记识别码，或录制后解码）
- 频率计 / 时间基准（校核 5 分钟周期）
- 假负载或已调谐天线、功率计（测功率范围）
- 秒表/铷钟级时间参考（校核周期误差）

## 4. 步骤

1. 设置码速 10WPM 与 12WPM，用示波器测量点（dit）与划（dah）的实际时长，
   计算码速误差。
2. 录制识别码音频，逐字符核对识别码内容是否正确。
3. 确认 **1KHz 长音**仅在**标准距离模式**下出现，且仅位于**发信结束前 2 秒**。
4. 测键控包络的软起与软降时间（10%–90% 或按定义）。
5. 运行完整的 5 分钟周期，用时间基准比对周期长度误差。
6. 人为制造 SWR>3.0 的负载，确认设备**禁止发射**并上报状态。
7. 通过 `SET_POWER` 在 0.02W–2.5W 范围内取多点，用功率计读实际输出。
8. 🔴 **调谐探测期门限验证（2026-09-27 定案新增）**：接一个能造出
   `3.0 < SWR ≤ 10.0` 的负载（旧门限 10.0 下**不会**否决、新门限 3.0 下**必须**否决
   —— 这正是本次改动可被观测的差异带），发起 `REQUEST_TUNE`，确认：
   (a) 探测载波在该组合上被**立刻关断**（而非"照测不误"）；
   (b) **不**置 `SWR_HIGH`、**不**锁存（调谐过程本身不得把整机钉成永久禁发）；
   (c) 载波被**重建**、搜索**继续**并最终给出结果（不是"整轮失败"）。
   ⚠️ 若 (a) 不成立 ⇒ 说明探测期门限被改回了 >3.0，即"独立门限"被重新引入，属**不合格**。

## 5. 判据

| 指标 | 判据 | 实测 | 结论 |
| --- | --- | --- | --- |
| 码速 10–12 WPM | 误差 **<2%** | | |
| 识别码正确性 | 逐字符正确 | | |
| 1KHz 长音 | 仅标准距离模式，且位于发信结束前 **2 秒** | | |
| 软起软降时间 | **2–5ms** | | |
| 5 分钟周期误差 | **<0.1 秒** | | |
| SWR 保护 | SWR>**3.0** 时禁止发射 | | |
| SWR 保护（探测期）| 🔴 探测期**同门限** 3.0：`3.0 < SWR ≤ 10.0` 的组合**必须**被实时否决（关载波但不锁存），且载波能重建、搜索继续 | | |
| 功率可调范围 | **0.02–2.5W** 全程可调且单调 | | |
| 边带/杂散（键控瞬间） | 无异常尖峰（与 stage-6 交叉验证） | | |
