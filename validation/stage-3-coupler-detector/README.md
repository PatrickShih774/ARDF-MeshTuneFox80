# stage-3-coupler-detector —— 定向耦合器与检波电路

- 时间窗：第 7–9 天
- 状态：未开始

## 1. 验证目标

验证 FT37-43 磁环绕制的 T1/T2 定向耦合器的耦合度、方向性与带内平坦度，
并确认检波后 SWR 读数精度满足 ATU 判决要求。

## 2. 被测对象

- T1：1 匝穿芯 + 10 匝次级（FT37-43）；T2 同批次绕制
- 检波器件：1N5711（肖特基）与 HSMS-2850 并行对照
- 前向/反射检波输出至 ADC 通道

## 3. 仪器与工装

- 信号源 / Si5351 激励板（3.50 / 3.55 / 3.60MHz）
- 功率计与 2W 假负载、可调失配负载（用于 SWR=1.2/1.5/2.0 与 50Ω 基准）
- 数字示波器 / 六位半万用表（读检波直流电压）
- 频谱分析仪或 SDR（用于杂散与耦合度辅助确认）

## 4. 步骤

1. 在 2W 激励下测 T1/T2 的耦合度，三点频率各测一次。
2. 正向/反向接入顺序对调，测方向性（前向与反射端口隔离度）。
3. 分别接 50Ω、以及非 50Ω 失配负载，比对仪器 SWR 与检波换算 SWR 的读数误差。
4. 在 3.50 / 3.55 / 3.60MHz 三点测检波输出，计算带内平坦度。
5. 将检波管在 1N5711 与 HSMS-2850 之间切换，重复步骤 1–4 做并行对照。
6. 2W 发射下读前向检波 ADC 值，换算为满量程百分比。
7. 接 SWR=2.0 负载，读反射检波 ADC 值，换算为满量程百分比。
8. 依次接 SWR=1.2 / 1.5 / 2.0 负载，每档重复 10 次，统计均值与标准差并做区分度检验。
9. 同一负载重复 10 次测量，计算标准差。

## 5. 判据

| 指标 | 判据 | 实测 | 结论 |
| --- | --- | --- | --- |
| 耦合度（2W） | **20±3dB** | | |
| 方向性 | **>25dB** | | |
| 非 50Ω 下 SWR 读数误差 | **<0.2** | | |
| 带内平坦度（3.50/3.55/3.60MHz） | **<1.0dB** | | |
| 检波管对照 | 1N5711 与 HSMS-2850 完成并行对照并给出选型结论 | | |
| 前向 ADC 位置（2W） | 落在量程 **20%–80%** | | |
| 反射 ADC（SWR=2.0） | ≥量程 **5%** | | |
| SWR 区分度 | 1.2/1.5/2.0 三档差值 **>3σ** | | |
| 重复性（10 次） | 标准差 **<0.15** | | |
