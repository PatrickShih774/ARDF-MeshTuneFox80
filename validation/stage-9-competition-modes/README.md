# stage-9-competition-modes —— 六种赛事模式

- 时间窗：第 23–24 天
- 状态：未开始

> **软件侧验证**：验证对象是固件赛事模式与调度逻辑。
> 对应固件组件：**`ardf_mode`**（模式定义与参数集）、**`ardf_schedule`**（发射窗口与台号时序），
> 协同 `rf_keyer`（CW）与 `rf_pa`（功率）。

## 1. 验证目标

逐一验证六种 ARDF 赛事模式的时序、频点、功率与识别码是否符合竞赛规则要求。

## 2. 被测对象

- `ardf_mode`：标准距离 / 短距离 / 快速测向 / 定向猎狐 / 阳光测向 / 短距离定向猎狐
- `ardf_schedule`：发射窗口时序、台号分配、周期循环
- 协同组件：`rf_keyer`、`rf_pa`、`atu_tuner`

## 3. 仪器与工装

- 已调谐整机 + 假负载（测功率）或实架天线（测时序与识别码）
- 示波器 / 逻辑分析仪（打时间戳）或录制设备 + 时间基准
- 频率计或 SDR（测频点与间隔）
- 功率计（测各模式功率）
- 秒表 / 时间基准（校核 5 分钟与 1 分钟周期）

## 4. 步骤

1. 逐一切换到六种模式，每种模式先确认参数集（频率、功率、码速、周期）加载正确。
2. **标准距离**：记录完整周期的发射起止时刻，比对时序误差。
3. **短距离**：依次触发 11 个频点，用频率计/SDR 测各频点并核对间隔。
4. **快速测向**：测 1 分钟周期与 12 秒发射段的时间误差。
5. **定向猎狐**：用功率计测输出功率，与设定值比较误差。
6. **阳光测向**：用功率计核实输出功率低于 0.1W。
7. **短距离定向猎狐**：录制并核对该模式的识别码内容。
8. 每种模式连续运行 ≥3 个周期，确认无累积漂移、无窗口重叠、无漏发。

## 5. 判据

| 指标 | 判据 | 实测 | 结论 |
| --- | --- | --- | --- |
| 标准距离时序误差 | **<0.1 秒** | | |
| 短距离频点 | **11 个频点，间隔 10kHz** | | |
| 快速测向周期 | **1 分钟 / 12 秒**，误差 **<0.1 秒** | | |
| 定向猎狐功率误差 | **<10%** | | |
| 阳光测向功率 | **<0.1W** | | |
| 短距离定向猎狐识别码 | 正确 | | |
| 模式参数加载 | 六种模式参数集均正确 | | |
| 多周期稳定性 | 连续 ≥3 周期无漂移、无重叠、无漏发 | | |

- 实测报告：`report-YYYYMMDD.md`，**六种模式分节填写**，每种模式一张判据表。
