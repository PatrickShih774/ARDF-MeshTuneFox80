# 专项验证区（validation/）

本目录承载《计划书》**第八章「ATU 专项验证方案」**的 **10 个验证阶段**，是项目的
**硬件在环（Hardware-in-the-Loop）实测区**。

## 1. 定位

| | `validation/`（本区） | 私有固件仓的 `test/` |
| --- | --- | --- |
| 性质 | **硬件在环实测** | **代码单元测试** |
| 对象 | 真实电路板、真实天线、真实仪器 | 纯逻辑函数、驱动 Mock |
| 工具 | NanoVNA、SDR、示波器、万用表、假负载 | Unity / pytest-embedded |
| 判据 | 射频指标、时间精度、成功率 | 断言通过率、覆盖率 |
| 产物 | 实测报告 + 原始数据（`.csv`/`.s2p`/`.png`） | 测试日志 |

两者互补：单元测试保证"代码算得对"，本区保证"板子真的行"。

## 2. 阶段总表

| 阶段 | 时间窗 | 验证对象 | 关键判据（摘要） |
| --- | --- | --- | --- |
| [`stage-0-rf-frontend`](stage-0-rf-frontend/README.md) | 第 0–1 天 | 5m 天线 + 5m 地线的复阻抗实测 | 所需串联电感落在 **0–92µH**、并联电容落在 **0–472pF**；记录 Smith 圆图匹配轨迹；测 43 材质磁环 3.5MHz 的 µ'' |
| [`stage-1-relay-rf`](stage-1-relay-rf/README.md) | 第 1–3 天 | HK4100F 继电器射频性能与驱动电路 | 插损 **<0.1dB @3.5–3.6MHz**、隔离 **>40dB**、100 次切换接触电阻变化 **<20mΩ**、2.5W 连续 30min 漂移 **<30mΩ**；BS170 壳温 **<85°C**；PWM 调压 0.02–0.1W 可用；2N7002 栅极无振铃、漏极吸合 **<0.1V**、释放反峰 **<20V**；1µF 反峰 **<25V**；吸合 **<6ms**、释放 **<4ms**；6 只同时吸合 **<110mA** |
| [`stage-2-matching-network`](stage-2-matching-network/README.md) | 第 4–6 天 | 6 继电器 L 型匹配网络全组合 | 遍历 **64 种组合**；50Ω 下 ≥**8** 种 SWR<1.2；100/150Ω 与 10/20Ω 各 ≥**3** 种 SWR<2.0；挂树 **120-j1050Ω** 在 33µH 档 SWR<2.5；实验室 **50-j1110Ω** 在 47µH 档 SWR<1.8；**88-j1030Ω** 在 45µH 档 SWR<2.0；R 扫 115–135Ω 时 SWR<2.5；电容谐振高压测试 |
| [`stage-3-coupler-detector`](stage-3-coupler-detector/README.md) | 第 7–9 天 | FT37-43 绕制的 T1/T2 定向耦合器与检波 | 耦合度 **20±3dB @2W**、方向性 **>25dB**、非 50Ω 下 SWR 读数误差 **<0.2**、带内 3.50/3.55/3.60MHz 平坦度 **<1.0dB**；1N5711 与 HSMS-2850 并行对照；2W 下前向 ADC 落在量程 **20%–80%**；SWR=2.0 时反射 ADC ≥量程 **5%**；SWR 1.2/1.5/2.0 差值 **>3σ**；重复 10 次标准差 **<0.15** |
| [`stage-4-opamp`](stage-4-opamp/README.md) | 第 10–11 天 | 检波后级：直接进 ADC vs LM358 缓冲 | 若「检波直接进 ADC」达标则**优先采用**该方案（省件、省失调） |
| [`stage-5-tuning-algorithm`](stage-5-tuning-algorithm/README.md) | 第 12–14 天 | ATU 调谐算法（粗调 + 细调 + 全遍历兜底） | 首次调谐 **<5s**、NVS 微调 **<0.5s**、成功率 **>95%**；统计 NVS 命中率 |
| [`stage-6-antenna-emc`](stage-6-antenna-emc/README.md) | 第 15–18 天 | 实架天线 + 电磁兼容 | 实架 5m 导线 + 5m 地线在 2W 下调谐 SWR **<2.0**；SDR 测杂散，2 次谐波 7.1MHz 衰减 **≥55dB**；12V 升压轨动态负载纹波峰峰值 **<0.5V** |
| [`stage-7-mesh`](stage-7-mesh/README.md) | 第 19–20 天 | Mesh 组网（软件侧，`net_espnow`/`mesh_router`） | 3 台从机 + 1 台主控，遮挡主控与其中 1 台，回传成功率 **>80%** |
| [`stage-8-cw`](stage-8-cw/README.md) | 第 21–22 天 | CW 键控（软件侧，`rf_keyer`） | 码速 10–12WPM 误差 **<2%**；识别码正确；1KHz 长音仅标准距离模式且位于发信结束前 2 秒；软起软降 **2–5ms**；5 分钟周期误差 **<0.1s**；SWR>3.0 禁止发射；功率 0.02–2.5W 可调 |
| [`stage-9-competition-modes`](stage-9-competition-modes/README.md) | 第 23–24 天 | 六种赛事模式（软件侧，`ardf_mode`/`ardf_schedule`） | 标准距离时序误差 **<0.1s**；短距离 11 个频点间隔 **10kHz**；快速测向 1 分钟/12 秒误差 **<0.1s**；定向猎狐功率误差 **<10%**；阳光测向功率 **<0.1W**；短距离定向猎狐识别码正确 |

> 时间窗为相对计划起点的工作日，非自然日；实际执行顺序可按物料到货情况微调，但判据不得放宽。

## 3. 记录规范

每个阶段目录下：

| 文件 | 内容 |
| --- | --- |
| `README.md` | **验证计划**：目标、被测对象、仪器工装、步骤、判据表、关联需求 |
| `report-YYYYMMDD.md` | **实测报告**：按判据表逐条填写实测值与结论，失败项必须留整改记录 |
| `raw/` | 原始数据：`.csv`、`.s2p`、`.png` 截图等（**已被 `.gitignore` 忽略**，不入库） |

- 大型原始数据统一放 `raw/` 或 [`validation/reports/`](reports/)；
  **禁止**把大文件提交进 Git 历史。
- 入库的只有：`README.md`、`report-*.md` 以及**压缩后小于 1MB** 的关键截图。
- 报告中的每个数字必须可追溯：注明仪器型号、量程、测点与测量次数。

## 5. 通用红线

1. 任何阶段出现**超标项**，必须先定位根因并留整改记录，不得直接放行到下一阶段。
2. 涉及发射的测试必须在**具备业余无线电操作资质**的人员在场、且使用假负载或合规天线时进行。
3. 记录须包含日期、环境温度与供电电压；射频测试前后各测一次假负载基准。
