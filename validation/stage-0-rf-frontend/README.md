# stage-0-rf-frontend —— 射频前端阻抗实测

- 时间窗：第 0–1 天
- 状态：未开始

## 1. 验证目标

实测 5m 天线 + 5m 地线在 **3.5MHz** 的复阻抗 `R ± jX`，确认 ATU 的电感/电容取值范围
足以覆盖全部预期负载，并提取磁环材料参数用于网络设计。

## 2. 被测对象

- 5m 导线天线 + 5m 地线（挂树、实验室两种架设场景）
- 43 材质磁环样品（T37-43 / T106-43），3.5MHz 下的复数磁导率虚部 µ''

## 3. 仪器与工装

- NanoVNA-H4（校准至测试端面，校准件：OSL）
- 假负载 50Ω、同轴测试线、鳄鱼夹引线（记录引线长度）
- 卷尺、绑扎带、树挂工装、温湿度计

## 4. 步骤

1. 对 NanoVNA 在 3.5MHz 附近（3.0–4.0MHz）做 OSL 校准，记录校准日期。
2. 在实验室场景架设 5m 导线 + 5m 地线，测 3.50 / 3.55 / 3.60MHz 的 `R + jX`。
3. 更换为挂树场景，重复步骤 2，记录架设高度与周围遮挡情况。
4. 每种场景重复测量 3 次，记录离散度。
5. 由实测 `X` 反算所需串联电感 `L = |X| / (2πf)`，由实测 `R` 估算所需并联电容。
6. 在 NanoVNA 上做 Smith 圆图匹配轨迹记录，导出截图与 `.s2p`。
7. 用磁环样品绕制测试电感，扫频提取 3.5MHz 下的 µ''。

## 5. 判据

| 指标 | 判据 | 实测 | 结论 |
| --- | --- | --- | --- |
| 所需串联电感 | 落在 **0–92µH** 区间 | | |
| 所需并联电容 | 落在 **0–472pF** 区间 | | |
| Smith 圆图 | 记录完整匹配轨迹（截图 + `.s2p`） | | |
| 43 材质磁环 µ'' @3.5MHz | 记录实测值，供网络损耗评估 | | |
| 重复性 | 同一场景 3 次测量 R、X 偏差可解释 | | |
